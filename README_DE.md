# Runtime FeedDownloader Pro
**Der leistungsstärkste Weg, Ihre Podcasts zu archivieren.**

## Was ist das
Runtime FeedDownloader Pro ist ein professionelles Tool für Archivare, Verleger und Enthusiasten, die ganze Podcast-Kataloge für die Offline-Aufbewahrung herunterladen müssen.
Im Gegensatz zu Standard-Playern ist diese Software für Massendownloads (Batch), Netzwerkresilienz und Dateisystemorganisation optimiert.

## Hauptmerkmale
- **"Database-First"-Engine:** Das System merkt sich, was Sie heruntergeladen haben, unabhängig von den Dateien auf der Festplatte.
- **Batch-Download:** Laden Sie Hunderte von Episoden mit einem Klick herunter, mit intelligenter Warteschlangenverwaltung.
- **Datenportabilität:** Importieren und exportieren Sie Ihre Feeds im OPML-Standard. Generieren Sie detaillierte CSV-Berichte Ihres Archivs.
- **Erweiterte Sicherheit:** Anti-Korruptionssystem für volle Datenträger, intelligenter Offline-Modus und Eingabe-Validierung für Feeds.
- **Integrierte Hilfe:** Vollständiges Benutzerhandbuch direkt in der Anwendung verfügbar.
- **Smart Truncate:** Benennt Dateien automatisch um, um Pfadlängenfehler unter Windows zu vermeiden.
- **Resilienz:** Versucht Downloads automatisch erneut, wenn die Verbindung abbricht.
- **Leistung:** Verarbeitet Feeds mit Tausenden von Episoden ohne Verlangsamung.

## Kurzanleitung
1.  **Analysieren:** Fügen Sie die RSS-Feed-URL in die Hauptleiste ein und drücken Sie "Analysieren".
2.  **Ordner wählen:** Klicken Sie auf das Ordner-Symbol, um zu entscheiden, wo das Archiv gespeichert werden soll.
3.  **Herunterladen:** Verwenden Sie die Taste "Alles herunterladen" für das gesamte Archiv oder laden Sie einzelne Episoden manuell herunter.
4.  **Verwalten:** Verwenden Sie die Einstellungen (Zahnradsymbol), um die Sprache zu verwalten oder die Datenbank zurückzusetzen.

## Systemanforderungen
Die Software ist plattformübergreifend und läuft nativ auf:
- **Windows**: 10/11 (64-Bit)
- **macOS**: 11.0 (Big Sur) oder höher (Intel & Apple Silicon)
- **Linux**: Moderne Distributionen (Ubuntu, Debian, Fedora) via AppImage oder .deb
- Aktive Internetverbindung
