# Добро пожаловать в Runtime FeedDownloader Pro
**Самый мощный и надежный способ архивирования ваших подкастов.**

## Что это такое?
Runtime FeedDownloader Pro — это профессиональный инструмент **Ecosystem Runtime | Digital Core**, разработанный для архивистов, издателей и энтузиастов, которым необходимо скачивать целые каталоги подкастов для автономного хранения.

В отличие от обычных плееров, это программное обеспечение оптимизировано для **массовой загрузки (Batch)**, устойчивости к сетевым сбоям и структурированной организации файлов на диске.

---

## Философия: "Database-First"
Сердцем FeedDownloader Pro является движок на базе **SQLite**. В отличие от других программ, которые полагаются исключительно на наличие файлов на диске, наша система:
1.  **Помнит каждую загрузку:** Даже если вы переместите архив на NAS или внешний диск, база данных сохранит состояние вашей коллекции.
2.  **Предотвращает дубликаты:** Больше никакой путаницы между файлами `.mp3`, `.m4a` или выпусками, скачанными несколько раз.
3.  **Документированная целостность:** каждый загруженный файл проверяется с помощью хэша SHA-256, а метаданные (битрейт, частота дискретизации) извлекаются автоматически.

## Уникальные особенности

### 1. Экстремальная сетевая устойчивость
Управление загрузкой сотен аудиофайлов требует безупречной обработки ошибок. FeedDownloader Pro реализует:
- **Автоматические повторы:** с экспоненциальной задержкой, чтобы не перегружать серверы.
- **Обнаружение зависания (Stall):** если сервер перестает отправлять данные в течение 60 секунд, загрузка перезапускается автоматически.
- **Файлы .part против повреждения данных:** файлы переименовываются в окончательное расширение только после полного завершения загрузки.

### 2. Безопасность и проверка (SSRF)
Приложение реализует 5-уровневую проверку anti-SSRF для каждого введенного URL-адреса. Мы блокируем опасные протоколы и частные IP-адреса, обеспечивая вашу безопасность даже при работе с RSS-каналами из неизвестных источников.

### 3. Профессиональная поддержка NAS/SMB
Разработанное для архивистов, программное обеспечение проверяет сетевые пути с 8-секундным тайм-аутом, предотвращая зависания интерфейса, характерные при работе с сетевыми дисками или NAS, которые не готовы к работе.
