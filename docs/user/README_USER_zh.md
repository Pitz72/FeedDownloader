# 欢迎使用 Runtime FeedDownloader Pro
**最强大且最具弹性的播客存档方式。**

## 什么是 FeedDownloader Pro？
Runtime FeedDownloader Pro 是 **Ecosystem Runtime | Digital Core** 的专业工具，专为需要下载整个播客目录以进行离线保存的存档员、出版商和爱好者而设计。

与普通播放器不同，此软件针对 **批量下载 (Batch)**、网络弹性和磁盘上的结构化文件组织进行了优化。

---

## 哲学：“数据库优先” (Database-First)
FeedDownloader Pro 的核心是基于 **SQLite** 的引擎。与仅依赖磁盘文件存在的其他软件不同，我们的系统：
1.  **记住每一次下载：** 即使您将存档移动到 NAS 或外部驱动器，数据库也会保持您的收藏状态。
2.  **防止重复：** 不再混淆 `.mp3`、`.m4a` 文件或多次下载同一集。
3.  **记录完整性：** 每个下载的文件都通过 SHA-256 哈希进行验证，并自动提取元数据（比特率、采样率）。

## 独特功能

### 1. 极强的网络弹性
管理数百个音频文件的下载需要无可挑剔的错误处理。FeedDownloader Pro 实现了：
- **自动重试：** 具有指数级退避机制，以避免服务器过载。
- **停滞检测 (Stall Detection)：** 如果服务器停止发送数据超过 60 秒，下载将自动重新开始。
- **防损坏 .part 文件：** 仅在下载完全完成后，文件才会重命名为最终扩展名。

### 2. 安全与验证 (SSRF)
该应用程序对每个输入的 URL 执行 5 级 anti-SSRF 验证。我们阻止危险协议和私有 IP 地址，即使使用来自未知来源的 RSS 订阅也能确保您的安全。

### 3. 专业级 NAS/SMB 支持
专为存档员设计，该软件以 8 秒的超时时间验证网络路径，防止在处理尚未就绪的网络驱动器或 NAS 时常见的界面冻结。
