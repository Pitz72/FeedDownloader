# ⚡ Runtime FeedDownloader Pro：快速入门指南

欢迎使用 **Runtime FeedDownloader Pro**。本指南将帮助您在 3 分钟内完成首次启动并建立您的第一个完整播客存档。

---

## 1. 分析 Feed

首先，告诉软件您要存档哪个播客：

1. 复制您要下载的播客的 **RSS 链接**（通常在播客网站上标有"RSS"、"Feed"或"Subscribe"等标签）。
2. 将其粘贴到界面顶部的**主搜索栏**中。
3. 点击**"分析"**按钮（或按 `Enter` 键）。
4. 软件将查询 Feed 并显示所有可用剧集的完整列表，包括标题、时长和发布日期。

> **提示：** 您可以将链接直接拖放到应用程序窗口上（拖放操作），无需使用搜索栏。

---

## 2. 选择下载目标

在开始下载之前，选择文件的保存位置：

1. 点击目标路径字段旁的**文件夹**图标。
2. 选择（或创建）您希望存档存储的文件夹。
3. 如果您使用 **NAS 或网络驱动器（SMB）**，请输入网络路径（例如 `\\NAS\Podcasts\`）。软件将在 8 秒内自动验证写入访问权限，不会冻结界面。

> **提示：** 为每个播客创建专用文件夹（例如 `D:\Archive\播客名称\`）。FeedDownloader Pro 将以有序的方式保存文件，并在其数据库中记住存储位置。

---

## 3. 开始下载

Feed 已分析完毕，文件夹已准备好。现在可以开始下载：

**选项 A — 下载完整目录：**
1. 点击主按钮**"全部下载"**。
2. 所有剧集将被添加到下载队列。
3. 软件将开始并行下载文件（线程数量可在设置中配置）。

**选项 B — 选择性下载：**
1. 在剧集列表中找到您感兴趣的剧集。
2. 点击该剧集旁边的**下载**图标（向下箭头）。
3. 您可以按住 `Ctrl` 键选择多个剧集，然后一起启动下载。

> **提示：** **Stall Detection（停滞检测）**系统会监控每次下载：如果服务器 60 秒内停止响应，下载将自动重启。您无需手动检查下载队列。

---

## 4. 队列管理

FeedDownloader Pro 工作时，您拥有完全控制权：

- **全局进度条：** 显示在界面底部，显示整个批次的进度（已完成/总文件数、平均速度）。
- **暂停 / 继续：** 点击**暂停**按钮暂停所有下载。准备好后，点击**继续**。
- **停止：** 停止批次下载。已完成的文件保留在数据库中。下次启动时，FeedDownloader Pro 将识别已下载的文件，避免重复下载。
- **托盘图标（通知区域）：** 您可以关闭主窗口：软件将继续在后台运行。通知区域（系统托盘）中的图标允许您随时重新打开应用或停止下载。

---

## 5. 导出和统计

下载完成后，访问**设置**（齿轮图标 ⚙️）使用高级功能：

- **导出 CSV：** 生成包含已下载剧集完整列表的电子表格文件（标题、URL、文件路径、SHA-256 哈希值、大小、比特率）。
- **导入/导出 OPML：** 与其他应用或其他软件用户共享您的 Feed 列表。
- **存档统计：** 查看已占用磁盘空间、剧集总数以及完整性摘要（通过 SHA-256 验证的文件）。
- **重命名模板：** 使用 `{{title}}`、`{{date}}`、`{{podcast}}` 等标记自定义文件命名格式，让存档井然有序。

## 实用技巧与故障排查

**Feed 无法识别：**
确保 URL 直接指向 RSS 文件地址（通常以 `.xml` 或 `.rss` 结尾）。部分网站显示包含 Feed 链接的 HTML 页面：请使用那个链接。

**某些剧集无法下载（404 错误）：**
该剧集已从播客服务器删除。FeedDownloader Pro 会将错误记录到数据库中，不会阻止其他下载。这正是及时存档至关重要的原因之一。

**NAS 路径无法访问：**
在开始下载之前，确保 NAS 已开机并在本地网络中可访问。如果使用 SMB 凭据，请确保共享已挂载（或在 Windows 中配置了凭据）。

**软件因"磁盘空间不足"停止下载：**
在目标位置释放空间，然后重新启动批次下载。得益于数据库，已下载的文件不会被重复下载。
