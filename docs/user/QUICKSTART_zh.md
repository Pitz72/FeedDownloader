# ⚡ Runtime FeedDownloader Pro：快速入门指南

欢迎使用 **Runtime FeedDownloader Pro**。本指南将帮助您在 3 分钟内完成首次启动并建立您的第一个完整播客存档。

---

## 1. 分析 Feed

首先，告诉软件您要存档哪个播客：

1. 复制您要下载的播客的 **RSS 链接**（通常在播客网站上标有"RSS"、"Feed"或"Subscribe"等标签）。
2. 将其粘贴到界面顶部的**主搜索栏**中。
3. 点击**"分析"**按钮（或按 `Enter` 键）。
4. 软件将查询 Feed 并显示所有可用剧集的完整列表，包括标题、时长和发布日期。Feed 会自动添加到左侧边栏，以便日后访问。

> **提示：** 您可以将链接直接拖放到应用程序窗口上（拖放操作），无需使用搜索栏。

---

## 2. 选择下载目标

在开始下载之前，选择文件的保存位置：

1. 前往**设置 → 存档**，点击目标路径字段旁的**文件夹**图标。
2. 选择（或创建）您希望存档存储的文件夹。
3. 配置的路径始终显示在左侧边栏底部：点击可直接在文件管理器中打开该文件夹。
4. 如果您使用 **NAS 或网络驱动器（SMB）**，请输入网络路径（例如 `\\NAS\Podcasts\`）。软件将在 8 秒内自动验证写入访问权限，不会冻结界面。

> **提示：** 为每个播客创建专用文件夹（例如 `D:\Archive\播客名称\`）。FeedDownloader Pro 将以有序的方式保存文件，并在其数据库中记住存储位置。

---

## 3. 开始下载

Feed 已分析完毕，文件夹已准备好。现在可以开始下载：

**选项 A — 下载完整目录：**

1. 点击剧集列表标题栏中的主按钮**"全部下载"**。
2. 所有剧集将被添加到下载队列。
3. 软件将开始并行下载文件（线程数量可在设置中配置）。

**选项 B — 选择性下载：**

1. 在剧集列表中找到您感兴趣的剧集。
2. 点击鼠标悬停时出现在该剧集旁边的**下载**图标（向下箭头）。
3. 要选择多个剧集，请按住 `Ctrl` 键逐个点击（或使用 `Shift`+点击 选择范围），然后点击**"下载所选 (N)"**。

> **提示：** **Stall Detection（停滞检测）**系统会监控每次下载：如果服务器 60 秒内停止响应，下载将自动重启。

---

## 4. 下载监控

当您启动一个批次时，**下载面板**会自动在窗口右侧打开。

* **显示内容：** 队列中的每个剧集，包含进度百分比、当前速度（KB/s 或 MB/s）及预计完成时间。
* **取消单个下载：** 将鼠标悬停在面板中的剧集上，点击出现的 **×** 按钮。
* **停止全部：** 点击面板标题栏中的**停止**按钮。
* **关闭面板而不停止下载：** 点击面板右上角的 **×**。右下角会保留一个**浮动按钮**：点击它可随时重新打开面板。
* **错误日志：** 批次结束时，如果某些剧集下载失败，面板会显示一个可展开的摘要，包含标题和错误代码。
* **后台运行：** 您可以点击 X 关闭主窗口：软件将继续在通知区域（系统托盘）运行，下载不会中断。

> **提示：** 随时按 **Ctrl+K** 打开命令面板：在那里您可以启动"同步所有 Feed"、打开设置或切换到其他播客，无需使用鼠标。

---

## 5. 导出和统计

下载完成后，访问**设置**（齿轮图标 ⚙️）使用高级功能：

* **导出 CSV：** 生成包含已下载剧集完整列表的电子表格文件（标题、URL、文件路径、SHA-256 哈希值、大小、比特率）。
* **导入/导出 OPML：** 与其他应用或软件的另一个安装实例共享您的 Feed 列表。
* **存档统计：** 查看已占用磁盘空间、剧集总数以及存档中的不同播客数量。
* **重命名模板：** 使用 `{{title}}`、`{{date}}`、`{{podcast}}` 等标记自定义文件命名格式，让存档井然有序。
* **导出 M3U：** 通过剧集列表标题栏中的"导出 M3U"按钮，生成包含某个播客所有已下载剧集本地路径的播放列表。

## 实用技巧与故障排查

**Feed 无法识别：**
确保 URL 直接指向 RSS 文件地址（通常以 `.xml` 或 `.rss` 结尾）。部分网站显示包含 Feed 链接的 HTML 页面：请使用那个链接。

**某些剧集无法下载（404 错误）：**
该剧集已从播客服务器删除。FeedDownloader Pro 会将错误记录到下载面板中，不会阻止其他下载。这正是及时存档至关重要的原因之一。

**NAS 路径无法访问：**
在开始下载之前，确保 NAS 已开机并在本地网络中可访问。如果使用 SMB 凭据，请确保共享已挂载（或在 Windows 中配置了凭据）。

**软件因"磁盘空间不足"停止下载：**
在目标位置释放空间，然后重新启动批次下载。得益于数据库，已下载的文件不会被重复下载。
