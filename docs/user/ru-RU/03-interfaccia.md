# Глава 3: Обзор интерфейса

## 3.1 Структура главного окна

При открытии FeedDownloader Pro окно организовано в четыре функциональные зоны:

*   **Командная панель (вверху):** Закреплённая панель, содержащая поле URL, кнопку «Анализировать» и значок «Настройки». Все операции по добавлению новых каналов начинаются отсюда.
*   **Боковая панель каналов (слева):** Колонка, содержащая постоянную библиотеку сохранённых каналов, вкладку «Архив», элементы управления синхронизацией и нижний колонтитул с путём назначения. Ширину можно настроить, перетаскивая правую границу.
*   **Основная область (центр):** Область, где отображаются эпизоды выбранного канала, с панелью фильтров, элементами управления пакетом и списком эпизодов.
*   **Панель загрузок (справа, поверх):** Панель, которая открывается автоматически при запуске пакета загрузок. Когда закрыта, в правом нижнем углу остаётся видимой плавающая кнопка для её повторного открытия.

При первом запуске, когда библиотека пуста, в основной области отображается приветственное сообщение, объясняющее, как добавить первый канал и где настроить путь назначения. Сообщение автоматически исчезает при добавлении первого канала или вручную с помощью кнопки ×.

---

## 3.2 Командная панель (Вверху)

**Поле URL:** Текстовая строка, в которую вводится RSS-адрес анализируемого подкаста. Принимает прямые URL к XML/RSS-файлам. Поддерживает **перетаскивание**: можно перетащить ссылку прямо из браузера в эту область.

**Кнопка «Анализировать»:** Запускает анализ канала. Программа обращается к URL, считывает RSS-файл и заполняет список эпизодов. По завершении анализа канал постоянно добавляется в боковую панель. Операция обычно занимает от 1 до 5 секунд в зависимости от размера канала и скорости соединения.

**Значок «Настройки» (⚙):** Открывает панель настроек. Доступен в любой момент, даже во время активной загрузки. Подробнее см. главу 10.

---

## 3.3 Боковая панель каналов

Боковая панель — это центр управления библиотекой подкастов. Содержит все каналы, добавленные на постоянной основе: каналы не теряются при закрытии программы.

### Вкладки «Каналы» и «Архив»

В верхней части боковой панели расположены две вкладки:

*   **Вкладка «Каналы»:** Показывает библиотеку сохранённых каналов. Это вид по умолчанию.
*   **Вкладка «Архив»:** Показывает Архивный вид — таблицу со всеми загруженными эпизодами по всей библиотеке. См. раздел 3.10.

### Элементы библиотеки каналов

Каждый канал в списке представлен строкой, в которой отображаются:

*   **Миниатюра:** Обложка подкаста.
*   **Название:** Имя подкаста, как оно заявлено в RSS-канале.
*   **Дата:** Дата последней синхронизации с сервером.
*   **Значок новых эпизодов:** Числовой индикатор, показывающий, сколько эпизодов было опубликовано с момента последней загрузки. Значок исчезает после загрузки всех новых эпизодов.

Щелчок по элементу в списке загружает список эпизодов этого канала в основную область.

### Добавление канала

Вставьте RSS-адрес в поле URL в верхней части интерфейса и нажмите «Анализировать». После завершения анализа канал автоматически добавляется в боковую панель и остаётся доступным в последующих сеансах.

### Поиск и сортировка

*   **Поиск каналов:** Поле поиска на боковой панели фильтрует каналы по имени в реальном времени. Полезно при больших библиотеках.
*   **Сортировка А–Я:** Кнопка сортировки упорядочивает каналы по алфавиту. Повторный щелчок восстанавливает исходный порядок.

### Синхронизация

*   **Индивидуальная синхронизация:** При наведении курсора на элемент канала появляется значок синхронизации. По щелчку программа повторно считывает канал с сервера и обновляет список эпизодов любым новым содержимым.
*   **Синхронизировать всё:** Кнопка «Синхронизировать всё» в верхней части боковой панели обновляет все каналы параллельно. Во время операции каждая миниатюра показывает собственный статус: вращающийся значок (в процессе), зелёная галочка (готово), красный значок ошибки (сбой). Кнопка показывает прогресс в реальном времени (напр. `Синхронизация… 3/7`). Статусы остаются видимыми 2,5 секунды после операции, затем исчезают.

### Нижний колонтитул: путь назначения

В нижней части боковой панели отображается путь к папке назначения загрузок, сокращённый до двух последних компонентов (напр. `Документы / Подкасты`). Щелчок по этой строке открывает папку в файловом проводнике системы. Чтобы изменить путь, используйте **Настройки → Архив**.

### Изменение размера

Ширину боковой панели можно настроить, перетаскивая правую границу (курсор превращается в двойную горизонтальную стрелку). Минимальная ширина — 240 пикс., максимальная — 640 пикс., значение по умолчанию — 456 пикс. Настройка сохраняется между сеансами.

## 3.4 Список эпизодов

После выбора канала на боковой панели основная область заполняется списком эпизодов, доступных для этого подкаста.

### Заголовок канала

В верхней части основной области виден заголовок выбранного канала с миниатюрой, названием подкаста и количеством эпизодов. Основные элементы управления пакетом доступны из этого заголовка (см. раздел 3.7).

### Колонки списка

Каждая строка списка представляет эпизод и содержит следующую информацию:

*   **Название:** Название эпизода, как оно определено в RSS-канале.
*   **Дата:** Дата исходной публикации эпизода.
*   **Длительность:** Длительность эпизода (если доступна в канале).
*   **Размер:** Размер файла. До загрузки значение является декларативным (взято из канала); после загрузки отражает фактический размер файла.
*   **Статус:** Визуальный индикатор состояния отдельного эпизода. См. раздел 3.5.

### Панель фильтров

Под заголовком канала находится панель фильтров, позволяющая сузить список отображаемых эпизодов:

*   **Текстовый поиск:** Фильтрует по ключевым словам в названии (логика И: все введённые термины должны присутствовать). Фильтр автоматически очищается при смене канала.
*   **Фильтр по статусу:** Быстрые кнопки для отображения только эпизодов в определённом состоянии: Все, Новые (не загруженные), Загруженные, Ошибки.
*   **Фильтр по дате:** Поля даты «От» и «До» для ограничения списка диапазоном дат публикации.
*   **Фильтр по длительности:** Ограничивает список эпизодами с длительностью между минимумом и максимумом (в минутах).
*   **Сортировка:** Открывает панель с пятью вариантами сортировки — порядок канала (по умолчанию), новые сначала, старые сначала, длинные сначала, короткие сначала.

Все фильтры автоматически очищаются при выборе другого канала.

### Множественный выбор

Можно одновременно выбрать несколько эпизодов, чтобы запустить их пакетную загрузку:

*   **Ctrl+щелчок** (или Cmd+щелчок в macOS): добавляет или удаляет эпизод из выбора индивидуально.
*   **Shift+щелчок:** выбирает диапазон между последним выбранным эпизодом и тем, по которому щёлкнули.
*   Флажок появляется при наведении курсора на невыбранные эпизоды и всегда виден на выбранных эпизодах.

При наличии хотя бы одного выбранного эпизода в заголовке канала появляется кнопка **«Загрузить выбранные (N)»**. Выбор очищается при смене канала и после запуска загрузки.

## 3.5 Состояния эпизодов

Каждый эпизод в списке помечен индикатором состояния. Понимание этих состояний необходимо для правильной интерпретации состояния архива.

| Состояние | Цвет | Значение |
|-----------|------|----------|
| **К загрузке** | Серый | Эпизод присутствует в канале, но никогда не загружался. |
| **В очереди** | Синий | Эпизод добавлен в очередь и ожидает своей очереди на Панели загрузок. |
| **В процессе** | Анимированный светло-синий | Загрузка в процессе. Строка показывает процент, скорость и расчётное время в реальном времени. |
| **Завершено** | Зелёный | Файл загружен, переименован и проверен корректно. |
| **Ошибка** | Красный | Загрузка не удалась после всех автоматических повторных попыток. |
| **Загружено** | Приглушённый зелёный | База данных уже регистрирует этот эпизод как загруженный в предыдущем сеансе. |

*Заметка о состоянии **«Загружено»**:* Это состояние — результат философии Database-First. При анализе уже обработанного канала большинство эпизодов появятся в этом состоянии: программа уже знает, что они присутствуют в архиве. Только эпизоды, опубликованные после последней загрузки, появятся как **«К загрузке»**.

## 3.6 Индивидуальные элементы управления загрузкой

Справа от каждой строки списка при наведении курсора появляются кнопки управления, специфичные для эпизода. Видимые кнопки различаются в зависимости от состояния:

**Для всех эпизодов:**

*   **Копировать название** (значок документа): Копирует название эпизода в системный буфер обмена.
*   **Флажок:** Для множественного выбора (см. раздел 3.4).

**Для эпизодов «К загрузке» или с «Ошибкой»:**

*   **Загрузить** (стрелка вниз): Добавляет отдельный эпизод в очередь загрузки.

**Для «Завершённых» или «Загруженных» эпизодов:**

*   **Перезагрузить** (стрелка вниз): Снова добавляет эпизод в очередь, перезаписывая существующий файл.
*   **Сбросить состояние** (значок обновления): Сбрасывает состояние эпизода, возвращая его к «К загрузке» без удаления файла с диска. Полезно для принудительного повторного анализа.
*   **Открыть папку** (значок папки): Открывает файловый проводник системы в расположении загруженного файла.

**Взаимодействие с Панелью деталей:**
**Одиночный щелчок** по строке эпизода открывает Панель деталей (см. раздел 3.9) с полными метаданными и контекстными действиями. Ctrl+щелчок и Shift+щелчок зарезервированы исключительно для множественного выбора и не открывают панель.

## 3.7 Элементы управления пакетом

Элементы управления пакетом действуют на всю очередь загрузки, а не на отдельные эпизоды. Они находятся в заголовке канала, над панелью фильтров.

**«Загрузить всё»:** Добавляет в очередь все эпизоды в состоянии **«К загрузке»**. Эпизоды, уже присутствующие в базе данных, автоматически исключаются. Панель загрузок открывается автоматически при запуске.

**«Загрузить выбранные (N)»:** Появляется, когда выбран хотя бы один эпизод. Запускает загрузку только для выбранных эпизодов.

**«Остановить»:** Отправляет сигнал отмены всем активным загрузкам и очищает очередь. Уже завершённые файлы остаются в базе данных. Файлы `.part` удаляются. При следующем анализе прерванные эпизоды снова появятся как **«К загрузке»**.

**«Экспорт M3U»:** Создаёт плейлист в формате `.m3u` с абсолютными локальными путями всех загруженных эпизодов этого подкаста. Открывает нативное диалоговое окно сохранения. Кнопка доступна только при наличии загруженных эпизодов для текущего канала.

**«Открыть папку»** (значок папки в заголовке): Открывает файловый проводник в папке назначения текущего канала.

## 3.8 Панель загрузок

Панель загрузок — это центр мониторинга и управления всеми текущими загрузками. Заменяет прежнюю фиксированную полосу прогресса в нижней части интерфейса.

### Открытие и закрытие

Панель открывается **автоматически** при запуске каждого пакета. Когда закрыта, **плавающая кнопка** (круглый значок) видна в правом нижнем углу окна: щелчок по ней снова открывает панель. Закрытие панели не прерывает текущие загрузки.

### Структура панели

*   **Заголовок:** Показывает счётчик завершённых/всего файлов (напр. `47 / 312`), кнопку «Остановить» для прерывания всех загрузок и кнопку × для закрытия панели.
*   **Список очереди:** Каждая текущая или ожидающая загрузка представлена строкой с: названием эпизода, именем подкаста, процентом прогресса, текущей скоростью (КБ/с или МБ/с), расчётным временем до завершения (напр. `2 мин 30 с`), индивидуальной полосой прогресса. При наведении курсора на строку появляется кнопка × для отмены этой отдельной загрузки.
*   **Раздел ошибок:** В конце пакета, если одна или несколько загрузок не удались, в нижней части панели появляется разворачиваемая сводка со списком незагруженных эпизодов и их кодами ошибок.

## 3.9 Панель деталей эпизода

Панель деталей предоставляет углублённый обзор отдельного эпизода: метаданные, действия и — если эпизод уже в архиве — технические данные загруженного файла.

### Открытие панели деталей

**Одиночный щелчок** по любой строке в списке эпизодов открывает панель, которая выезжает с правой стороны окна (под командной панелью). Панель закрывается автоматически при выборе другого канала на боковой панели.

*Заметка:* Ctrl+щелчок и Shift+щелчок зарезервированы для множественного выбора и не открывают панель.

### Содержимое панели

*   **Основные метаданные:** Дата публикации, заявленная длительность, размер файла, указанный в канале.
*   **Контекстные действия:** Доступные кнопки различаются в зависимости от состояния эпизода: Загрузить, Перезагрузить, Сбросить состояние, Открыть папку.
*   **Данные архива** (видны только если эпизод уже загружен): Дата и время загрузки, фактический размер файла, битрейт, частота дискретизации, имя файла на диске, контрольная сумма SHA-256.
*   **Ссылка на источник:** Исходный URL аудиофайла в RSS-канале, с кнопкой для копирования в буфер обмена.
*   **Заметки об эпизоде:** Описательный текст эпизода, извлечённый из канала (show notes), представленный в виде чистого текста.

## 3.10 Архивный вид

Архивный вид доступен через вкладку **Архив** на боковой панели. В отличие от списка эпизодов, который показывает только эпизоды одного канала за раз, Архивный вид объединяет в единой таблице **все эпизоды, загруженные во всей библиотеке**, независимо от подкаста, к которому они относятся.

### Функциональные возможности

*   **Поиск:** Поле поиска фильтрует по названию эпизода или имени подкаста.
*   **Фильтр по подкасту:** Выпадающее меню позволяет ограничить отображение эпизодами одного подкаста.
*   **Сортировка:** Таблицу можно отсортировать по дате загрузки, дате публикации, размеру файла и битрейту.
*   **Статистика:** В заголовке Архивного вида отображается общее количество загруженных файлов, число различных подкастов и общий размер архива в гигабайтах.
*   **Показать в папке:** При наведении курсора на строку появляется кнопка, открывающая файловый проводник в расположении файла на диске.

Архивный вид автоматически обновляется по завершении каждой загрузки.

## 3.11 Палитра команд (Ctrl+K)

Палитра команд — это инструмент быстрого доступа, позволяющий получить доступ к любой основной функции программы без использования мыши.

### Открытие палитры команд

Сочетание **Ctrl+K** (из любой точки приложения, даже во время загрузки) открывает наложение с центральным полем поиска.

### Навигация

*   **Ввод** в поле поиска фильтрует действия и каналы в реальном времени.
*   **Стрелки ↑↓** перемещают выбор между результатами.
*   **Enter** выполняет выбранное действие.
*   **Esc** закрывает палитру без выполнения какого-либо действия.

### Содержимое

*   **Группа «Действия»:** Пять фиксированных команд, всегда доступных: *Открыть настройки*, *Синхронизировать все каналы*, *Добавить канал* (фокусирует поле URL), *Перейти на вкладку Архив*, *Перейти на вкладку Каналы*.
*   **Группа «Каналы»:** Когда поле поиска пустое, показывает первые пять каналов библиотеки. При вводе фильтрует каналы по названию. Выбор канала из палитры загружает его непосредственно в основную область.

## 3.12 Значок в системном трее

Когда главное окно закрывается щелчком по X, FeedDownloader Pro не завершает процесс: сворачивается в область уведомлений системы (системный трей, рядом с часами Windows или macOS). Это поведение задумано специально: загрузки продолжаются в фоновом режиме, пока окно не видно.

**Контекстное меню трея (правый щелчок по значку):**

*   **Открыть FeedDownloader Pro:** Возвращает главное окно на передний план.
*   **Состояние загрузок:** Показывает строку-резюме текущей активности.
*   **Выход:** Закрывает программу и останавливает все активные загрузки.

*Практическая заметка:* Чтобы выполнить большую загрузку, не держа окно открытым, запустите пакет, закройте окно и оставьте компьютер работать. Архив будет доступен по завершении процесса.
