第 3 章：界面导览

3.1 主窗口结构

打开 FeedDownloader Pro 后，界面在垂直方向上分为三个功能区域：

  • 命令区（顶部）： URL 输入栏和主要控件。所有操作均从此处发起。
  • 工作区（中部）： 主要区域，显示已分析的节目及其相关信息和单个下载控件。
  • 状态区（底部）： 全局进度条，显示当前批量任务的信息。

3.2 命令栏（顶部）

URL 字段： 用于输入要分析的播客 RSS 地址的文本栏。接受直接指向 XML/RSS 文件的 URL。支持 drag and drop：可以直接从浏览器将链接拖放到此区域。

"分析"按钮： 启动 feed 分析。软件访问 URL，读取 RSS 文件，并填充节目列表。根据 feed 大小和连接速度，此操作通常需要 1 至 5 秒。

目标路径字段： 显示已下载文件的保存文件夹。点击旁边的文件夹图标可打开选择窗口。设置的路径在会话之间保持不变。

设置图标（⚙）： 打开设置面板。可在任意时刻访问，即使在下载进行中也可操作。详情参见第 10 章。

3.3 节目列表（中部）

分析 feed 后，此区域将显示可用节目列表。每行代表一个节目，包含以下信息。

主要列：

  • 标题： RSS feed 中定义的节目名称。
  • 日期： 节目的原始发布日期。
  • 时长： 节目时长（若 feed 中有此信息）。
  • 大小： 文件估计大小（若 feed 中有此信息）。下载前为声明值；下载后反映文件实际大小。
  • 状态： 单个节目状态的视觉指示器。参见第 3.4 节。
  • 操作： 每个节目的单独控制按钮。

排序： 列标题可点击以对列表排序（按日期、按标题、按大小）。默认行为是将最新节目显示在顶部。

多选： 按住 Ctrl 并点击可逐个选择多个节目。Shift + 点击可选择一个范围。可对选中的节目应用批量操作（开始下载、从列表中移除）。

3.4 节目状态

列表中每个节目都标有彩色状态指示器。理解这些状态对于正确解读存档情况至关重要。

状态 颜色 含义
待下载 灰色 节目存在于 feed 中，但从未被下载过。
排队中 蓝色 节目已加入队列，等待轮次。
下载中 动态浅蓝色 正在进行下载。单元格还会显示进度百分比。
已完成 绿色 文件已成功下载、重命名并验证。
错误 红色 经过所有自动重试后下载仍失败。悬停提示显示错误代码。
已下载 浅绿色 数据库中已记录此节目为已下载。不会重新下载。

关于"已下载"状态的说明： 此状态是数据库优先理念的体现。当分析之前已处理过的 feed 时，大多数节目会显示为此状态：软件已知它们存在于存档中。只有上次下载后新发布的节目才会显示为"待下载"。

3.5 单个下载控件

每行右侧有两个按钮。

下载图标（↓）： 将单个节目添加到下载队列。如果节目已处于"已完成"或"已下载"状态，系统会在执行强制重新下载前要求确认。

信息图标（ℹ）： 打开一个包含节目完整详情的面板：音频原始 URL、封面图片 URL、详细描述、磁盘上的文件路径（若已下载）、SHA-256 哈希值以及技术元数据。此面板对存档验证和诊断很有用。

3.6 批量控件（顶部右侧区域）

这些按钮对整个下载队列进行操作，而非单个节目。

"全部下载"： 将所有处于"待下载"状态的节目添加到队列。数据库中已有记录的节目会被自动排除。

"停止"： 中断批量任务并清空队列。已完成的文件保留在数据库中。.part 文件将被删除。下次分析同一 feed 时，被中断的节目将重新显示为"待下载"。

3.7 全局进度条（底部）

底部栏始终可见，显示当前批量任务的整体状态：

  • 进度条： 按已完成文件数占队列总数的比例填充。
  • 文件计数器： 例如 47 / 312 个节目——已完成文件数占队列总数。
  • 平均速度： 所有活动线程的综合下载速度，以 MB/s 或 KB/s 表示。
  • 预计时间： 完成批量任务所需剩余时间的估计值，根据过去 30 秒的平均速度计算。

注意： 在下载初期，由于可用于计算的数据有限，剩余时间估计可能波动较大。完成前 10–15 个文件后，估计值将变得更加可靠。

3.8 系统托盘图标

点击 X 关闭主窗口时，FeedDownloader Pro 不会终止进程，而是最小化到系统通知区域（system tray，位于 Windows 或 macOS 时钟附近）。这是有意为之的设计：窗口不可见时，下载在后台继续进行。

托盘右键菜单：

  • 打开 FeedDownloader Pro： 将主窗口恢复到前台。
  • 下载状态： 显示摘要行（例如 Downloading: 3 active, 47/312 completed）。
  • 退出： 关闭程序并中止所有活动下载。

实用提示： 如需在不保持窗口打开的情况下执行大型下载，可启动批量任务后关闭窗口，让计算机持续运行。存档将在任务完成时可用。
