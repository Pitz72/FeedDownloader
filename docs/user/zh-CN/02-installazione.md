# 第 2 章：安装与首次启动

## 2.1 系统要求

Runtime FeedDownloader Pro 是一款基于 Electron 技术的桌面应用程序。它是自包含的，无需安装额外运行时（Node.js、.NET、Java）：安装包中已包含所有必要组件。

**最低要求：**

| 操作系统 | 最低版本 | 架构 |
|----------|----------|------|
| Windows | 10（内部版本 1903）或 Windows 11 | 64 位（x64） |
| macOS | 11.0 Big Sur | Intel x64 或 Apple Silicon（M1/M2/M3） |
| Linux | Ubuntu 22.04 LTS、Debian 11、Fedora 36 或同等发行版 | 64 位（x64） |

**推荐硬件配置：**
*   **内存：** 4 GB（对于使用多线程的大型存档，建议 8 GB）
*   **磁盘空间：** 程序安装需 200 MB，另加音频存档所需空间
*   **网络：** 宽带连接（至少 10 Mbps，以有效使用并行下载功能）

*Linux 用户注意事项：* 软件以 `.AppImage` 格式分发，自包含，可在任何具有最新 glibc 库的现代发行版上使用，无需传统安装流程。

---

## 2.2 在 Windows 上安装

1.  从官方发布页面下载安装文件 `Runtime-FeedDownloader-Pro-Setup-1.3.0.exe`。
2.  双击下载的文件以启动安装程序。
3.  如果 Windows 显示 **"Windows 已保护你的电脑"**（SmartScreen）警告，请点击 **"更多信息"**，然后点击 **"仍要运行"**。此警告是通过 Microsoft Store 以外渠道分发、且尚未达到 Windows 信誉系统所需采用门槛的软件的标准提示。
4.  按照屏幕提示操作：接受许可协议，选择安装文件夹，然后点击 **"安装"**。
5.  安装完成后，**桌面**上将出现快捷方式，**开始**菜单中也会出现相应条目。

**安装路径与数据路径：**
程序安装在 `C:\Program Files\Runtime FeedDownloader Pro\`。数据库和配置文件单独保存在 `C:\Users\[你的用户名]\AppData\Roaming\FeedDownloaderPro\`。这种分离确保卸载程序不会影响存档数据。

---

## 2.3 在 macOS 上安装

1.  下载文件 `Runtime-FeedDownloader-Pro-1.3.0.dmg`。
2.  双击 `.dmg` 文件将其打开。将弹出一个包含应用程序图标的窗口。
3.  将 **FeedDownloader Pro** 图标拖入 **应用程序** 文件夹，如 `.dmg` 窗口中的箭头所示。
4.  **macOS 首次启动：** 由于软件不通过 Mac App Store 分发，首次打开时 macOS 会显示安全警告。处理方法：
    *   前往 **系统设置 → 隐私与安全性**。
    *   在"安全性"部分可看到消息 *"FeedDownloader Pro 已被阻止……"*。
    *   点击 **"仍要打开"**，然后在确认窗口中点击 **"打开"**。
    *   之后每次启动时，软件均可通过双击正常打开。

*Apple Silicon（M1/M2/M3）用户注意事项：* 提供原生 ARM 版本。为获得最佳性能，请下载带有 `-arm64` 后缀的 `.dmg` 文件。x64 版本可通过 Rosetta 2 运行，但 ARM 版本效率更高。

---

## 2.4 在 Linux 上安装

1.  下载文件 `Runtime-FeedDownloader-Pro-1.3.0.AppImage`。
2.  将文件设为可执行。可通过以下方式之一操作：
    *   **通过图形界面：** 右键点击文件 → 属性 → 权限选项卡 → 勾选"允许将文件作为程序执行"。
    *   **通过终端：** `chmod +x Runtime-FeedDownloader-Pro-1.3.0.AppImage`
3.  双击文件启动，或在终端中执行：`./Runtime-FeedDownloader-Pro-1.3.0.AppImage`

**桌面集成（可选）：**
如需将 FeedDownloader Pro 添加到启动器和应用程序菜单，可使用 **AppImageLauncher**（大多数发行版的软件源中均有提供），它能自动将 AppImage 文件集成到系统中。

*沙盒环境注意事项：* 在使用 **Flatpak** 或具有文件系统访问限制的环境中，软件可能无法访问 SMB 网络路径。在这种情况下，请在启动程序前确认网络文件系统已挂载，并可通过文件管理器正常访问。

---

## 2.5 首次启动

首次打开软件后可立即使用，无需任何初始配置，也无需创建账户或输入许可证。界面中央显示 URL 输入栏，节目列表为空。

**首次启动时创建的文件：**
程序会在用户数据文件夹中自动生成以下文件：
*   `feeddownloader.db` — 主 SQLite 数据库。包含完整的下载历史、节目元数据和存档状态。**此文件不得删除。**
*   `settings.json` — 用户偏好设置（语言、线程数、默认目标文件夹等）。
*   `logs/` — 日志文件文件夹，在出现问题时用于诊断。

---

## 2.6 更新

当有新版本可用时，软件会在界面底部状态栏显示通知。安装更新始终需要用户明确同意。

更新前，软件会自动备份数据库。无论如何，存档数据在更新过程中不会被修改：仅替换程序文件。

*注意：* 在升级到主要版本（例如从 1.2.x 升级到 1.3.x）之前，建议将 `feeddownloader.db` 文件手动复制到安全位置。
