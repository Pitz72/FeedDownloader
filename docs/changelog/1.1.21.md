# Changelog v1.1.21

## F5 — Export playlist M3U

Esporta gli episodi scaricati di un podcast come file `.m3u` con i path locali, pronto per VLC, mpv, Plex o qualsiasi media player esterno.

### Funzionalità
- **Pulsante "Esporta M3U"** nel podcast header (icona `playlist_add_check`), visibile per tutti i feed
- Dialogo di salvataggio nativo con nome suggerito `<podcast>.m3u`
- Il file include `#EXTM3U` header e una voce `#EXTINF:-1,<titolo>` + path assoluto per ogni episodio scaricato, ordinati per data di pubblicazione (più recenti prima)
- Toast `m3u_exported` (success) se esportato correttamente
- Toast `m3u_empty` (info) se non ci sono episodi scaricati per quel podcast
- Nessun toast se l'utente annulla il dialogo

### Dettagli implementativi
- `EXPORT_M3U: 'export-m3u'` — nuovo canale IPC in `shared/types.ts`
- `getArchiveByPodcast(podcastTitle)` — query `WHERE podcastTitle = ? ORDER BY pubDate DESC` in `DatabaseService`
- Handler IPC: filtra `entries` per `filename` presente, costruisce path con `path.join(baseDir, sanitize(podcastTitle), filename)`, stessa logica del health check
- Ritorna `true` (ok), `false` (nessun entry), `null` (dialogo annullato)
- i18n: chiavi `episodes.export_m3u`, `toast.m3u_exported`, `toast.m3u_empty` in tutte e 8 le lingue
