# v0.6.10 — Migrazione archivio NAS

**Data:** 26 marzo 2026

## Nuova funzionalità

### Migrazione archivio verso un nuovo percorso (es. NAS)

Nella sezione **Archivio** delle impostazioni, il nuovo pulsante **"Migra Archivio"** permette di spostare fisicamente tutte le cartelle podcast verso un nuovo percorso e aggiornare automaticamente il percorso di download nelle impostazioni.

**Funzionamento:**

1. L'utente clicca "Migra Archivio" e sceglie la cartella di destinazione tramite il selettore di sistema.
2. L'app sposta ogni sottocartella (una per podcast) dalla posizione attuale a quella nuova.
3. Una barra di avanzamento mostra il progresso cartella per cartella.
4. Al termine, il percorso di download viene aggiornato automaticamente.

**Gestione degli errori:**

- Se il percorso di destinazione è lo stesso di quello corrente, viene mostrato un avviso e l'operazione viene annullata.
- Le cartelle che non è possibile spostare (es. permessi, conflitti) vengono conteggiate come errori nel messaggio finale.
- In caso di errori parziali, l'utente viene informato con il conteggio di cartelle spostate ed errori.

## Dettagli tecnici

- Nuovo canale IPC: `MIGRATE_ARCHIVE(newPath) → MigrationResult`
- Evento push: `MIGRATION_PROGRESS → MigrationProgress` (per aggiornamento UI in tempo reale)
- Usa `fs.move()` di `fs-extra` — gestisce automaticamente spostamenti cross-filesystem e verso NAS
- Il DB non richiede aggiornamenti: i record archivio contengono solo `podcastTitle` + `filename` (il percorso base è ricostruito dal `downloadPath` globale)
- Nuove interfacce TypeScript: `MigrationResult { moved, errors, newPath }`, `MigrationProgress { moved, total, currentFolder }`
- Nuove chiavi i18n: `settings.migrate_*` (7 chiavi) — in tutte e 8 le lingue
