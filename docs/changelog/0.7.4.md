# Changelog — v0.7.4 (27 marzo 2026)

## Verifica Integrità Post-Download

- **SHA-256 checksum**: dopo ogni download completato, viene calcolato l'hash SHA-256 del file scaricato tramite stream Node.js (`crypto.createHash`). L'hash viene salvato nella tabella `archive` del database.
- **Dimensione file**: la dimensione effettiva su disco (bytes) viene registrata in `archive.fileSize` tramite `fs.stat()`.
- **Metadati audio**: usando `music-metadata`, vengono estratti `bitrate` (kbps) e `sampleRate` (Hz) dal file audio e salvati nell'archivio.
- **Migrazione DB**: i campi `fileSize`, `checksum`, `bitrate`, `sampleRate` vengono aggiunti tramite `ALTER TABLE` silenzioso — i database esistenti vengono aggiornati senza perdita di dati (LEGACY per le voci precedenti).

## Filtri Avanzati per Keyword

- **AND multi-parola**: la ricerca episodi ora supporta più parole separate da spazio con logica AND (tutte le parole devono comparire nel titolo o nella descrizione).
- **Pulsante clear**: quando la ricerca è attiva, compare un'icona `×` nel campo di ricerca per resettarla con un click.

## Esportazione CSV Log Estesa

Il CSV esportato da _Impostazioni → Archivio → Esporta Inventario (CSV)_ ora include le colonne:

| Colonna | Descrizione |
|---|---|
| Podcast | Titolo del podcast |
| Episode Title | Titolo episodio |
| Publish Date | Data pubblicazione |
| Downloaded At | Data download |
| **File Size (bytes)** | Dimensione reale su disco |
| **Bitrate (kbps)** | Bitrate audio (da `music-metadata`) |
| **Sample Rate (Hz)** | Frequenza campionamento audio |
| **SHA-256 Checksum** | Hash integrità del file |
| **Validation Status** | `OK` = integrità verificata; `LEGACY` = file scaricato prima di v0.7.4 |
| GUID | Identificatore univoco episodio |
