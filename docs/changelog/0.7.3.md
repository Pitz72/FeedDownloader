# v0.7.3 — Allineamento UI: GlobalProgressBar

**Data:** 27 marzo 2026

## Modifiche

### GlobalProgressBar — design system completo

Pannello e controlli allineati al design system "Obsidian Command": tutte le classi Tailwind hardcoded (`bg-gray-900`, `border-white/10`, `text-green-400`, `bg-blue-500`, ecc.) sostituite con CSS design token.

**Pannello:**
- Sfondo: `var(--color-surface-container-low)`
- Bordo: `inset 0 0 0 1px rgba(65,71,85,0.25)`
- `backdropFilter: blur(20px)` per effetto glass

**Testo e contatori:**
- Label titolo: `var(--color-on-surface)` + `var(--font-label)`
- Contatore `X / Y`: `var(--color-primary)` + `font-mono`
- Icona completamento (`check_circle`): `var(--color-primary)`
- Testo "non chiudere": `var(--color-on-surface-variant)` opacity 0.55

**Pulsanti:**
- Stop (`stop` icon filled, 16px): hover `var(--color-error)` + `rgba(147,0,10,0.15)`
- Chiudi (`close` icon, 14px): hover `var(--color-on-surface)` + `var(--color-surface-container-high)`

**Barra di avanzamento:**
- Track: `var(--color-surface-container-highest)`
- Fill in download: gradiente `var(--color-primary-container)` → `var(--color-primary)`
- Fill completato: `var(--color-primary)` solido
