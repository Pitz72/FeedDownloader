# v0.1.9 - Gestione e Controllo

## ⚙️ Centro di Controllo (Impostazioni)
E' arrivato il nuovo pannello Impostazioni (icona ingranaggio nella sidebar):
- **Lingua**: Cambia rapidamente la lingua dell'interfaccia.
- **Percorso Download**: Vedi e modifica la cartella di destinazione.
- **Zona Pericolo (Reset DB)**: Un tasto di emergenza per dimenticare tutto lo storico dei download (senza cancellare i file fisici). Utile se vuoi riscaricare tutto da zero.

## 🔍 Ricerca e Filtri
- **Trova Subito**: Aggiunta una barra di ricerca nella lista episodi. Ora puoi filtrare centinaia di episodi in tempo reale digitando parte del titolo.

## ↩️ Correzione Storico (Un-archive)
- **Ripristina Stato**: Hai cancellato un file per sbaglio ma l'app dice che è ancora lì? Passa il mouse sulla spunta verde: apparirà un'icona di "Reset" (freccia circolare). Cliccala per dire all'app di "dimenticare" quel singolo download e permetterti di scaricarlo di nuovo.
