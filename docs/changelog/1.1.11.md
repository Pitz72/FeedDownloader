# v1.1.11 — 2026-05-11

## Fix

- **D11** — Pulsante download accessibile da tastiera (navigazione Tab).
  Il pulsante aveva `opacity-0 group-hover:opacity-100 focus:opacity-100`: visibile al mouse,
  ma il `focus:` generico non produceva feedback visivo durante la navigazione con Tab.
  Sostituito con `focus-visible:opacity-100 focus-visible:ring-2 focus-visible:ring-[var(--color-primary)]`:
  il pulsante compare e mostra un anello di focus colorato solo quando raggiunto via tastiera,
  senza modificare il comportamento al mouse.
  File modificato: `src/components/EpisodeList.tsx`.

- **D8 follow-up** — `IntroScreen.tsx` importava 8 componenti SVG da `country-flag-icons`
  (rimosso in v1.1.8), causando build failure. Le SVG flag sostituite con emoji Unicode
  (`🇬🇧`, `🇮🇹`, `🇫🇷`, `🇩🇪`, `🇪🇸`, `🇵🇹`, `🇷🇺`, `🇨🇳`) — nessuna dipendenza esterna,
  rendering nativo del browser/Electron.
  File modificato: `src/components/IntroScreen.tsx`.
