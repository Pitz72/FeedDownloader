# v0.0.4 - Libreria e Miglioramenti UX

## 🆕 Nuove Funzionalità
- **Sidebar Libreria**: Ora i feed salvati sono visibili in una comoda barra laterale. Puoi passare da un podcast all'altro con un click.
- **Sistema di Notifiche**: Sostituiti i vecchi avvisi di sistema con notifiche "Toast" moderne ed eleganti.
- **Stato Download Persistente**: L'applicazione ora ricorda quali episodi hai scaricato, mostrandoti una spunta verde anche dopo il riavvio.

## 🛠️ Miglioramenti Tecnici
- **Sanificazione File**: Migliorata la pulizia dei nomi dei file per evitare errori di salvataggio su Windows.
- **Gestione Errori**: Migliorata la gestione degli errori durante il parsing e il download.
- **UI Refresh**: Miglioramenti visivi alla lista episodi e all'input URL.

## 🐛 Bug Fixes
- Risolto un problema per cui i feed non venivano salvati correttamente se non si impostava una cartella di download.
- Corretti vari errori di tipizzazione TypeScript.
- Rimossi log di debug eccessivi.
