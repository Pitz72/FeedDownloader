# Changelog v0.3.3 (2026-02-16)

## 🔴 Critical Fixes & Stability
- **IPC Handlers Fixed:** Resolved a critical issue where `remove-history-item` and `reset-history` were missing their main-process handlers, causing silent crashes when resetting history or forgetting individual downloads.
- **Build Configuration Consolidated:** Removed the redundant and misconfigured `electron-builder.json5`. All build metadata is now correctly centralized in `package.json` using the official `com.runtime.feeddownloader.pro` ID.

## 🌍 Internationalization (I18n)
- **100% Localization Reached:** Completed all missing translations for **French, German, Spanish, Portuguese, Russian, and Chinese**. 
- All 8 supported languages now correctly include the **Settings** and **Help** sections, previously missing or partial in non-IT/EN locales.
- Fixed fallback logic for missing keys to ensure a consistent UI across all languages.

## 📝 Documentation
- Verified and aligned `README_*.md` files with the latest features (CSV Export, OPML Portability, and Database Reset).
- Cleaned up project root from legacy configuration files.
