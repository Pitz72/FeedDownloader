# v0.1.2 - Performance & Icon Fixes

## ⚡ Performance
- **Virtualizzazione Lista Episodi**: Implementata la libreria `react-virtuoso` per la gestione di feed con centinaia di episodi.
    - Il rendering è ora istantaneo indipendentemente dal numero di episodi.
    - Utilizzo della memoria drasticamente ridotto grazie al DOM recycling.
    - Scrolling nativo fluido integrato con la finestra principale.

## 🛠️ Bug Fixes
- **Icona Taskbar**: Risolto il problema dell'icona mancante o generica nella barra delle applicazioni di Windows (configurato AppUserModelId).
