## Fix

### D2 — Import dinamici convertiti in statici in `ipc.ts`

**Problema:** Tre librerie venivano caricate con `await import()` all'interno di callback e loop:
- `music-metadata` — invocata ad ogni download completato per leggere bitrate/sampleRate
- `electron.shell` — invocata nel handler `SHOW_IN_FOLDER`
- `sanitize-filename` — invocata dentro il `for...of` dell'health check

Node.js cachea le dynamic import dopo il primo caricamento, ma il pattern è semanticamente scorretto e introduce overhead misurabile al primo ciclo di ogni sessione.

**Fix applicato in:** `electron/ipc.ts`

- `import { ..., shell } from 'electron'` — aggiunto `shell` all'import statico esistente
- `import { parseFile as parseAudioMetadata } from 'music-metadata'` — nuovo import statico in cima
- `import sanitize from 'sanitize-filename'` — nuovo import statico in cima (coerente con `getSafePath.ts`)
- Rimosse le tre occorrenze di `await import(...)` inline
