# v0.5.3 — Sincronizzazione Incrementale Smart

> Rilasciato il 26 marzo 2026
> Versione precedente: [v0.5.2](0.5.2.md)

Aggiunto il pulsante **Sincronizza Nuovi** che ri-analizza il feed corrente e mette in coda automaticamente solo gli episodi non ancora scaricati. Risolve il caso d'uso principale del data hoarding: tornare su un podcast dopo settimane e scaricare solo le nuove uscite senza dover filtrare manualmente.

---

## ✅ Nuova Feature

### Sincronizzazione Incrementale Smart

**File modificati:** `src/components/EpisodeList.tsx`, `src/locales/*.json` (8 lingue)

#### Flusso operativo

1. L'utente clicca **Sincronizza Nuovi** (tasto verde con icona `RefreshCw`)
2. L'app ri-analizza il feed RSS tramite `window.api.parseFeed(currentFeed.url)`
3. Vengono filtrati gli episodi il cui `guid` NON è già in `downloadedGuids`
4. I nuovi episodi vengono accodati automaticamente tramite `handleDownload(ep, true)`
5. Toast di feedback: `"X nuovi episodi in coda"` oppure `"Nessun nuovo episodio da scaricare"`

#### Caratteristiche

- **Non interrompe** i download attivi — i nuovi episodi vengono accodati nella queue esistente (`QueueService` con concorrenza configurata)
- **Spinner animato** durante il re-parse del feed (`isSyncing` state → `animate-spin` sull'icona)
- **Disabilitato** in modalità offline o mentre è già in corso un sync
- **Non sovrascrive** il feed corrente visualizzato — solo mette in coda, non aggiorna la lista UI (per non confondere l'utente durante la navigazione)

#### Implementazione

```typescript
const [isSyncing, setIsSyncing] = useState(false);

const handleSyncNew = async () => {
    if (!currentFeed || !isOnline || isSyncing) return;
    setIsSyncing(true);
    try {
        const freshFeed = await window.api.parseFeed(currentFeed.url);
        const newEpisodes = freshFeed.episodes.filter((ep: Episode) => {
            const url = getEnclosureUrl(ep);
            const guid = ep.guid || url || '';
            return guid ? !downloadedGuids.includes(guid) : false;
        });
        if (newEpisodes.length === 0) {
            toast.show(t('toast.sync_none'), 'info');
            return;
        }
        startBatch(newEpisodes.length);
        toast.show(t('toast.sync_queued', { count: newEpisodes.length }), 'success');
        newEpisodes.forEach((ep: Episode) => handleDownload(ep, true));
    } catch {
        toast.show(t('toast.feed_error'), 'error');
    } finally {
        setIsSyncing(false);
    }
};
```
