# v0.5.2 — Filtro Stato Episodi

> Rilasciato il 26 marzo 2026
> Versione precedente: [v0.5.1](0.5.1.md)

Aggiunta la possibilità di filtrare la lista episodi per **stato di download**: Tutti / Da scaricare / Scaricati. Feature di immediata utilità per archivi di grandi dimensioni (podcast con 300+ episodi) dove si vuole visualizzare solo il lavoro rimanente.

---

## ✅ Nuova Feature

### Filtro Stato Episodi

**File modificati:** `src/components/EpisodeList.tsx`, `src/locales/*.json` (8 lingue)

Un nuovo gruppo di 3 pulsanti nella toolbar dell'EpisodeList permette di filtrare la lista visuale per stato:

| Stato | Comportamento |
|---|---|
| **Tutti** (default) | Nessun filtro aggiuntivo — stesso comportamento v0.5.1 |
| **Da scaricare** | Mostra solo episodi il cui `guid` NON è in `downloadedGuids` |
| **Scaricati** | Mostra solo episodi il cui `guid` è in `downloadedGuids` |

Il filtro si **combina** con gli altri filtri esistenti (testo, data range): es. si può cercare per keyword E filtrare solo i non scaricati simultaneamente.

#### Implementazione

```typescript
// Tipo
type StatusFilter = 'all' | 'new' | 'downloaded';
const [statusFilter, setStatusFilter] = useState<StatusFilter>('all');

// Logica nel useMemo (dopo testo e data range)
if (statusFilter !== 'all') {
    episodes = episodes.filter((ep: Episode) => {
        const url = getEnclosureUrl(ep);
        const guid = ep.guid || url || '';
        const isDownloaded = guid ? downloadedGuids.includes(guid) : false;
        return statusFilter === 'downloaded' ? isDownloaded : !isDownloaded;
    });
}

// Dipendenze useMemo aggiornate
}, [currentFeed, searchQuery, dateFrom, dateTo, downloadedGuids, statusFilter]);
```

#### UI

Gruppo di pulsanti compatti affiancati con stile active/inactive coerente con il design system esistente, posizionati nella toolbar dopo il pulsante "Filtro Data".

## 🌍 Localizzazione

Aggiunte 3 chiavi i18n nella sezione `episodes` di tutti e 8 i file locale:

| Chiave | IT | EN | FR | DE | ES | PT | RU | ZH |
|---|---|---|---|---|---|---|---|---|
| `filter_all` | Tutti | All | Tous | Alle | Todos | Todos | Все | 全部 |
| `filter_new` | Da scaricare | Not Downloaded | Non téléchargés | Nicht heruntergeladen | No descargados | Não descarregados | Не скачанные | 未下载 |
| `filter_downloaded` | Scaricati | Downloaded | Téléchargés | Heruntergeladen | Descargados | Descarregados | Скачанные | 已下载 |
