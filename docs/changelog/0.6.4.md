# v0.6.4 — Tagging ID3 Automatico

**Data:** 26 mar 2026

## Descrizione

Iniezione automatica di metadati ID3 nei file `.mp3` scaricati, leggendoli dal feed RSS. Feature opt-in (default OFF) attivabile dalle impostazioni.

## Novità

- **`electron/utils/writeId3Tags.ts`** — Nuova utility asincrona che scrive tag ID3 (`title`, `artist`, `album`, `year`) nel file `.mp3`. Se disponibile, scarica anche la cover art dall'URL immagine del feed (timeout 10s, fallback silenzioso in caso di errore).
- **Solo file `.mp3`** — Skip silenzioso per `.m4a`, `.ogg` e altri formati.
- **Errori non bloccanti** — Qualsiasi errore in `writeId3Tags` viene catchato e loggato; il download risulta comunque completato.
- **Toggle nelle Impostazioni** — Pill toggle identico a quello del Sidecar JSON, nella sezione Storage.
- **`feedImageUrl` in `DownloadRequest`** — Il campo opzionale viene passato da `EpisodeList` usando `currentFeed.image` (sia `string` che `{ url: string }`).
