# v1.1.22 — Vista Archivio Integrata (F1)

**Data:** 12 maggio 2026

## Feature: F1 — Vista archivio integrata in-app

L'archivio degli episodi scaricati è ora navigabile direttamente dall'applicazione senza aprire file CSV esterni.

### Cosa è stato aggiunto

**Navigazione tramite tab sidebar:**
- Due tab nella sidebar: **Feed** (default) e **Archivio** (con icona `inventory_2`)
- Switching istantaneo tra vista feed e vista archivio

**Vista archivio (pannello principale):**
- Tabella virtualizzata (react-virtuoso) con tutti gli episodi scaricati
- Colonne: Podcast, Episodio, Scaricato il, Dimensione, Bitrate
- Ordinamento cliccabile su: data download, data pubblicazione, dimensione, bitrate
- Ricerca full-text per titolo episodio e nome podcast
- Filtro per singolo podcast (dropdown con tutti i podcast presenti)
- Statistiche in header: N file · M podcast · totale occupato
- Pulsante "Mostra in cartella" on-hover per ogni riga con file presente su disco

**Aggiornamento in tempo reale:**
- La lista archivio si ricarica automaticamente ad ogni download completato (via `onDownloadsUpdated`)
