# Changelog v1.3.6

**Data:** 29 maggio 2026

## Hardening sicurezza Electron

Blocco 5/5 (finale) della risoluzione delle criticità gravi (audit 29 maggio 2026).

### B8 — Content-Security-Policy e hardening della navigazione

Mancavano CSP, `setWindowOpenHandler` e gestione di `will-navigate`: un link nel
contenuto di un feed poteva far navigare via la finestra o aprirne di nuove, e senza CSP
qualsiasi futura falla XSS avrebbe potuto caricare risorse remote.

* **CSP** applicata via `onHeadersReceived` (solo nelle build pacchettizzate — il dev server
  Vite richiede inline/eval e il websocket HMR):
  `default-src 'self'`; `script-src 'self'`; `object-src 'none'`; `base-uri 'self'`;
  `frame-ancestors 'none'`; con eccezioni mirate per Google Fonts
  (`style-src … https://fonts.googleapis.com`, `font-src … https://fonts.gstatic.com`) e per
  le immagini remote dei feed (`img-src 'self' https: data:`).
* **`setWindowOpenHandler`** nega l'apertura di nuove finestre; i link `http(s)` vengono
  instradati al browser di sistema con `shell.openExternal`.
* **`will-navigate`** impedisce alla finestra di navigare fuori dall'app (dev server o
  `file://`); i link esterni aprono nel browser.
* Aggiunto `setPermissionCheckHandler` (oltre al `setPermissionRequestHandler` esistente) e
  `webSecurity: true` esplicito.

### B9 — `sandbox: false`: chiarito il motivo reale (sandbox completa rinviata)

Il commento attribuiva erroneamente il `sandbox: false` all'incompatibilità con
better-sqlite3 (che gira nel **main**, non nel preload). Il motivo reale è che il **preload
è compilato come ESM** (`preload.mjs`) e i preload **sandboxed devono essere CommonJS**.

* Commento corretto con la motivazione reale.
* L'abilitazione effettiva di `sandbox: true` richiede prima la migrazione della build del
  preload a CommonJS e una verifica di avvio dell'app: **rinviata** a un intervento dedicato
  e testabile a runtime, per non rischiare una regressione di caricamento non verificabile in
  questa fase. `contextIsolation: true` + `nodeIntegration: false` restano attivi.
