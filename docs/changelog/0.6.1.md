## Novità

### Resume dei Download Interrotti
I download interrotti (per disconnessione, crash o chiusura dell'app) vengono ora ripresi automaticamente dal punto di interruzione all'avvio successivo, senza riscaricare i dati già ricevuti.

**Come funziona:**
- Prima di ogni download, `DownloadService` controlla se esiste già un file `.part` nella cartella di destinazione
- Se trovato, invia l'header HTTP `Range: bytes=N-` dove `N` è la dimensione del file parziale
- Se il server risponde **206 Partial Content**, il download riprende in modalità append
- Se il server risponde **200 OK** (Range non supportato), il file parziale viene eliminato e il download ricomincia dall'inizio
- La barra di progresso mostra correttamente la percentuale tenendo conto dei byte già scaricati

**Gestione degli errori:**
- Su `DOWNLOAD_STALLED` o `DOWNLOAD_TIMEOUT`: il file `.part` viene **conservato** per permettere la ripresa al prossimo tentativo
- Su `INTEGRITY_CHECK_FAILED`: il file `.part` viene eliminato per forzare un download pulito
- Su errori di I/O (`ENOSPC`, `EPERM`): comportamento invariato

**Nessuna modifica visibile all'UI o al DB** — la feature è trasparente per l'utente.
