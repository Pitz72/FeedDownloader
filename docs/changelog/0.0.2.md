# Changelog v0.0.2 - Electron App Migration & Core Logic Port

## Overview
This release marks a significant architectural shift from a standalone Python script to a modern Electron desktop application. The core logic has been completely ported to TypeScript/Node.js, and a new React-based user interface has been implemented.

## 🚀 New Features & Improvements

### Architecture
-   **Electron + Vite + React + TypeScript**: Fully initialized project structure replacing the Python environment.
-   **Pure TypeScript Backend**: Ported all Python logic (`feedparser`, `requests`) to Node.js equivalents (`rss-parser`, `axios` streams, `fs-extra`).
-   **IPC Communication**: Robust Main-to-Renderer communication with type-safe APIs exposed via `contextBridge`.

### User Interface (UI/UX)
-   **Glassmorphism Design**: Implemented a modern, dark-themed UI using Tailwind CSS v4 with transparency and blur effects.
-   **State Management**: Integrated `zustand` for efficient global state handling (feeds, downloads, progress).
-   **Components**:
    -   `UrlInput`: Input field for RSS feed URLs with validation.
    -   `EpisodeList`: Virtualized list displaying podcast episodes with download status.
    -   `Dashboard`: Integrated stats overview.

### Core Functionality
-   **Feed Parsing**: Implemented `FeedService` using `rss-parser` to robustly handle podcast feeds.
-   **Download Manager**: Implemented `DownloadService` with `axios` streams, supporting progress tracking and cancellation (foundation laid).
-   **Concurrency Control**: integrated `p-queue` to manage simultaneous downloads (limit set to 3).
-   **Library Persistence**: Added `LibraryService` using `electron-store` to save feeds locally.

### Bug Fixes
-   Fixed Tailwind CSS v4 configuration issues (`@theme` directive).
-   Resolved `contextBridge` API exposure issues (`window.api` vs `window.electronAPI`).

## Technical Details
-   **Tailwind CSS v4**: Updated configuration to use the new `@import "tailwindcss";` and `@theme` syntax.
-   **Type Safety**: Comprehensive TypeScript interfaces for `Feed`, `DownloadProgress`, and IPC events.
