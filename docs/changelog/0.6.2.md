## Bug Fix

### Processo zombie alla chiusura della finestra
Cliccando la X della finestra, l'app non terminava ma restava in esecuzione
come processo in background (visibile nel Task Manager).

**Causa:** In v0.5.0 era stato introdotto un handler `win.on('close', ...)` che
intercettava l'evento e chiamava `win.hide()` invece di lasciare chiudere la finestra,
per implementare il "minimize to tray". Il processo continuava a girare con solo
l'icona nel system tray attiva.

**Fix:**
- Rimosso l'handler `close` che chiamava `event.preventDefault()` + `win.hide()`
- `window-all-closed` ora chiama sempre `app.quit()` su Windows/Linux
- Rimosso il flag `isQuiting` (dead code dopo la rimozione dell'handler)
- Il tray icon rimane attivo finché la finestra è aperta; alla chiusura l'icona sparisce

**Comportamento dopo il fix:**
- X della finestra → app si chiude completamente, nessun processo residuo
- Tray icon → disponibile mentre la finestra è aperta (click mostra/nasconde)
- Tray → Quit → stessa cosa della X
