# v0.1.7 - Sicurezza e Controllo

## 🛡️ Sicurezza File System
- **Smart Truncate**: Implementato un sistema intelligente che accorcia automaticamente i nomi dei file troppo lunghi per rispettare i limiti di Windows (MAX_PATH). Questo previene errori di salvataggio per episodi con titoli molto estesi.

## 💾 Persistenza "Database-First"
- **Memoria Indipendente**: Lo stato "Scaricato" (spunta verde) ora dipende esclusivamente dal database interno e non dalla presenza fisica del file. Se cancelli o sposti un file, l'app continuerà a considerarlo scaricato (evitando riscaricamenti accidentali).

## 🎛️ Controllo Download
- **Stop Batch**: Aggiunto un pulsante di "Stop" nella barra di progresso globale. Ora puoi interrompere in qualsiasi momento una coda di download massivo.
- **Apri Cartella**: Accanto agli episodi scaricati è apparsa una nuova icona "Cartella". Cliccandola, verrai portato direttamente al file scaricato in Esplora Risorse.
