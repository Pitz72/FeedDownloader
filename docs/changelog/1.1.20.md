# Changelog v1.1.20

## F2 — Badge "N nuovi" per feed in sidebar

Ogni voce feed nella sidebar mostra un badge con il numero di episodi non ancora scaricati, calcolato server-side senza richiedere parse aggiuntivi.

### Funzionalità
- **Badge pill** (background primary, testo bianco, 9px) accanto alla data nell'info block di ogni feed
- Mostrato solo quando il conteggio è > 0
- Sparisce automaticamente man mano che gli episodi vengono scaricati (aggiornato a ogni download completato via push `FEEDS_UPDATED`)
- Non mostrato per feed mai parsati (badge null = nessuna informazione disponibile)

### Dettagli implementativi
- `feeds.episodeCount INTEGER` — nuova colonna, aggiunta con `ALTER TABLE` idempotente in `init()`
- `updateEpisodeCount(url, count)` — chiamato in `PARSE_FEED` handler dopo ogni fetch di rete
- `getFeeds()` — refactored: JOIN con `archive` per calcolare `newCount = MAX(0, episodeCount - downloadedByTitle)` in JavaScript dopo due query separate (feeds + conteggi per podcast title)
- `FEEDS_UPDATED` push aggiunto anche al completamento di ogni singolo download (non solo al parse)
- `FeedEntry.newCount?: number | null` — campo opzionale aggiunto al tipo condiviso
