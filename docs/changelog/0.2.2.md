# v0.2.2 - Portabilità & UI Polish

## 🎨 UI/UX Tuning
- **Sidebar Espansa**: La barra laterale (Libreria) è stata allargata da 256px a 320px per migliorare la leggibilità dei titoli dei podcast più lunghi.
- **Intro Screen**: Il piccolo pulsante "Help" è stato sostituito da un pulsante **"LEGGI LA GUIDA"** grande e visibile, posizionato chiaramente sotto il tasto di avvio.

## 💾 Dati & Portabilità
Nuova sezione nelle Impostazioni per gestire i tuoi dati:
- **Import OPML**: Importa i tuoi feed da altri software (es. AntennaPod, Pocket Casts).
- **Export OPML**: Esporta la tua lista feed per backup o migrazione.
- **Export Inventario (CSV)**: Genera un report Excel-compatibile con l'elenco di tutti gli episodi scaricati, utile per archiviazione e catalogazione.

## 🛠️ Modifiche Solide
- **XML Parsing**: Integrata la libreria `fast-xml-parser` per una gestione robusta dei file OPML.
- **Archive Tracking**: Il sistema ora memorizza metadati dettagliati (Data pubblicazione, Data download) per ogni file scaricato, alimentando il report CSV.
