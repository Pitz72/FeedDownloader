# v0.7.0 — Redesign visivo "Obsidian Command"

**Data:** 27 marzo 2026

## Fix post-release (hotfix, stesso numero di versione)

### Font Material Symbols non caricato nel pacchetto Electron
Gli `@import @fontsource-*` nel CSS venivano ignorati dal bundler Tailwind v4: i file WOFF2 non finivano nel `dist/`, rendendo le icone come testo grezzo (es. "folder_open", "check_circle").

**Soluzione:** tutti gli import font spostati in `src/main.tsx` come import TypeScript — Vite li processa come moduli, copia i WOFF2 in `dist/assets/` con hash, e aggiorna le URL nel CSS automaticamente.

### Lista episodi incompleta e rottura al cambio feed
`Virtuoso` usava `useWindowScroll`, ma lo scroll avviene su `<main>`, non sul window. Questo causava la virtualizzazione di pochissimi item e lo smontaggio errato al cambio feed.

**Soluzione:** `useWindowScroll` sostituito con `customScrollParent` che punta a `<main id="main-scroll">` in App.tsx.

### `noise.svg` ERR_FILE_NOT_FOUND nella console
Il file era referenziato come `bg-[url('./noise.svg')]` nel CSS Tailwind v4, che generava un path relativo alla cartella `dist/assets/` dove il file non esiste.

**Soluzione:** `noise.svg` spostato in `src/assets/` e importato come modulo Vite in `IntroScreen.tsx`, che garantisce il path corretto nel build finale.

## Novità principali

### Nuovo sistema di design "Obsidian Command"

Revisione completa dell'interfaccia visiva ispirata a un'estetica OLED dark moderna. La logica applicativa, i canali IPC, il motore di download e la gestione del database rimangono invariati.

**Palette cromatica OLED:**
- Sfondo principale: `#131313` (near-black OLED)
- Superfici stratificate: `surface-container-lowest` → `surface-container-high` (4 livelli)
- Accent primario: `#7B8FFF` (indigo elettrico)
- Accent secondario: `#A78BFA` (viola)
- Supporto per colori success/warning/error semantici

**Tipografia a tre font:**
- **Epilogue** — titoli e heading principali
- **Inter** — corpo testo e UI generale
- **Space Grotesk** — etichette monospaziose, numerazione episodi, metadati tecnici

**Layout bento card:**
- Carte con `box-shadow: inset 0 0 0 1px rgba(65,71,85,0.15)` — senza bordi espliciti
- Classi utility: `.bento-card`, `.glass-panel`, `.glass-card`, `.btn-primary-gradient`
- Glass panels con `backdrop-filter: blur` e trasparenze calibrate

### Sostituzione completa delle icone: lucide-react → Material Symbols

Tutte le icone dell'applicazione sono state migrate da `lucide-react` a **Material Symbols Outlined** (Google).

**Motivazione:**
- Set di icone più completo e coerente con il nuovo design system
- Supporto nativo allo stato "filled" tramite `font-variation-settings`
- Font bundlato offline via `@fontsource-variable/material-symbols-outlined` (nessuna dipendenza CDN)

**Componente `Icon.tsx`:**
Nuovo wrapper `src/components/Icon.tsx` con API compatibile con il precedente utilizzo di lucide-react: props `name`, `size`, `filled`, `className`, `style`.

## Dettagli tecnici

### Font offline con @fontsource
- `@fontsource-variable/material-symbols-outlined` — icone variable font
- `@fontsource/epilogue` — heading font
- `@fontsource-variable/space-grotesk` — label/mono font
- Tutti i WOFF2 sono bundlati nel pacchetto npm: nessuna chiamata CDN a runtime

### Tailwind CSS v4 — tema CSS-native
Il tema è definito tramite blocco `@theme {}` in `src/index.css` (sintassi v4), senza `tailwind.config.js`. Include 30+ variabili CSS per palette, tipografia e spaziatura.

### Componenti aggiornati
Tutti i componenti UI hanno ricevuto classi Tailwind aggiornate:
- `App.tsx` — TopBar con gradient title, layout flat `flex h-screen`
- `Sidebar.tsx` — surface OLED, indicatore attivo border-left, cover art grayscale→color on hover
- `UrlInput.tsx` — glass-panel, icona `rss_feed`, pulsante `btn-primary-gradient`
- `EpisodeList.tsx` — bento card header, filter pills, numerazione Space Grotesk, hover states
- `SettingsModal.tsx`, `ConfirmModal.tsx`, `GlobalProgressBar.tsx`, `HelpModal.tsx`, `IntroScreen.tsx`, `ToastContext.tsx` — tutte icone aggiornate a Material Symbols
