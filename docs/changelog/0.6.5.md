# v0.6.5 — Throttling Velocità di Trasferimento

**Data:** 26 marzo 2026

## Novità

### Throttling Velocità Download (KB/s)
- Nuovo parametro `speedLimitKBps` in `DownloadService.downloadFile` e `attemptDownload`
- Implementato `createThrottleStream` in `electron/utils/throttleStream.ts`: Transform stream puro Node.js, zero dipendenze aggiuntive
- La stall detection rimane applicata sul raw stream di rete (non sul flusso throttled), garantendo correttezza
- Pipe condizionale: `response.data.pipe(throttle).pipe(writer)` se limite > 0, altrimenti pipe diretta
- Impostazione `speedLimitKBps` persistita in SQLite tramite `DatabaseService` (chiave `settings`)
- Default: 0 = illimitato

## Note Tecniche

- Algoritmo throttle: bucket temporale — calcola il ritardo atteso in base a `bytesSent / bytesPerSecond`, poi dorme la differenza rispetto al tempo reale. Nessun sleep attivo.
- Il progresso (callback `onProgress`) viene aggiornato sul raw stream (`response.data.on('data')`), non sul flusso throttled, per mantenere accuratezza.
- `0 KB/s` significa "illimitato" (nessun throttle applicato).
