## Fix

### Health Check — Segna file mancanti come non scaricati

**Problema:** Quando il Health Check dell'archivio rilevava file presenti nel database ma assenti su disco, li segnalava come "mancanti" ma non offriva alcun modo per rimediare. Gli episodi rimanevano spuntati come "scaricati" nella lista del podcast, impedendo di riscaricaricarli.

**Soluzione:** Dopo l'esecuzione del Health Check, se vengono trovati file mancanti, appare il pulsante **"Segna come non scaricati"**. Al click:
1. I guid dei file mancanti vengono rimossi dalla tabella `downloads` e dalla tabella `archive` in una singola transazione atomica.
2. Il renderer riceve un evento `DOWNLOADS_UPDATED` e aggiorna immediatamente la lista episodi — i file ora appaiono come disponibili per il download.
3. Il contatore "Mancanti" nella UI viene azzerato e viene mostrato un toast di conferma.

**Comportamento:**
- Il pulsante è visibile solo quando `healthResult.missing > 0`
- Durante l'operazione il pulsante mostra uno spinner e viene disabilitato
- L'operazione è cross-platform (Windows, macOS, Linux) — nessuna dipendenza da percorsi OS-specific

## Note tecniche

- La rimozione usa `DELETE ... WHERE guid IN (...)` — singola query per N file, efficiente e atomica.
- `pushEvent(mainWindow, DOWNLOADS_UPDATED, ...)` garantisce che la lista episodi in qualsiasi scheda aperta si aggiorni senza reload.
- Il contatore `total` della UI viene aggiornato ottimisticamente sottraendo i mancanti (ora `present === total`).
