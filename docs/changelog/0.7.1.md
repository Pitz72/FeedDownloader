# v0.7.1 — Rifinitura UI: IntroScreen e ConfirmModal

**Data:** 27 marzo 2026

## Modifiche

### IntroScreen — allineamento al design system "Obsidian Command"

La schermata di apertura usava ancora colori Tailwind hardcoded (`bg-[#0b1120]`, `bg-blue-600`, `text-gray-400`) invece dei CSS design token.

**Cambiamenti:**
- Sfondo: `#0b1120` → `var(--color-background)` `#131313`
- Titolo: font Epilogue esplicito via `var(--font-headline)`, gradiente `primary → secondary` tramite CSS vars
- Slogan: `text-gray-400` → `var(--color-on-surface-variant)`
- Selettore lingua: container usa `surface-container-low` + `inset-shadow`, bottone attivo usa `primary-container`
- Pulsante "Start": migrato a `.btn-primary-gradient` (coerente con il resto dell'app)
- Pulsante "Leggi la guida": sostituito con stile bento-glass, CSS vars per background e colore
- Rimosso glow radiale hardcoded blu, sostituito con radial-gradient basato su `color-primary` a bassa opacità
- Rimosso `skip` button con bordo `border-white/10`, sostituito con stile coerente a `color-on-surface-variant`

### ConfirmModal — design token e varianti semantiche

Il modal usava classi Tailwind colorate inline (`bg-red-500/10`, `bg-orange-600`, ecc.) senza usare il design system.

**Cambiamenti:**
- Sfondo card: `rgba(...)` derivato dai colori semantici del tema invece di classi Tailwind
- Bottone conferma: colore da CSS vars (`error-container`, `warning-container`, `primary-container`)
- Bottone annulla: `surface-container-highest` con hover su `surface-bright`
- Testo titolo: font `var(--font-headline)`, colore `var(--color-on-surface)`
- Testo messaggio: `var(--color-on-surface-variant)`
- Backdrop: `rgba(0,0,0,0.65)` con `backdrop-blur`
- Transizione di entrata: da `scale(0.9)` a `scale(0.92)` per risultato più morbido
- Icone variante: `danger → error (filled)`, `warning → warning (filled)`, `info → info (filled)`

### Nuovo token CSS `--color-warning`

Aggiunto al `@theme {}` in `index.css`:
- `--color-warning: #ffb770` (amber chiaro)
- `--color-warning-container: #6e3200` (amber scuro)
- `--color-on-warning: #4a2000`
