# Changelog v1.1.15

## E5 — Re-download episodio già scaricato

Aggiunto pulsante "Riscarica" diretto sugli episodi già completati.

### Funzionalità
- Nella riga episodio completato (marcata col check verde), appare on-hover un terzo pulsante con icona `download` prima di `restart_alt` e `folder_open`
- Cliccando si avvia immediatamente un nuovo download senza dover prima fare reset dello stato
- Il pulsante è disabilitato se l'app è offline (coerente con il comportamento degli altri download)
- Tooltip localizzato `episodes.redownload`

### Caso d'uso
Per Data Hoarding: riscaricare un episodio se il file locale è corrotto o mancante, senza il giro manuale reset → riscarica.

### File modificati
- `src/components/EpisodeList.tsx` — pulsante re-download nel ramo `isCompleted` di `renderEpisodeRow`
- `src/locales/it.json` + en/fr/de/es/pt/zh/ru — chiave `episodes.redownload`
