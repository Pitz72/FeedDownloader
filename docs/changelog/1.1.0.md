## Fix

### C7 — `FeedService` singola richiesta HTTP (elimina doppio fetch)

**Problema:** `parseFeed` effettuava due o tre richieste HTTP per ogni feed: prima `axios.head()` per rilevare redirect/content-type, poi `parser.parseURL(url)` che internamente eseguiva un ulteriore `GET`. Questo raddoppiava il traffico di rete, aumentava la latenza e duplicava le connessioni verso i server dei podcast.

**Fix applicato in:** `electron/services/FeedService.ts`

- Rimosso il pre-check `HEAD`
- Il feed viene scaricato con una singola `axios.get()` con `responseType: 'text'`
- Il content-type viene letto dall'header della risposta axios (non da una richiesta separata)
- Il contenuto viene passato direttamente a `parser.parseString(response.data)` invece di usare `parser.parseURL(url)`
- La logica di validazione HTML/XML è preservata intatta
- Il timeout (15s) e gli header `Accept` sono mantenuti

**Benefici:**
- Riduzione da 2–3 richieste HTTP a 1 per ogni parsing di feed
- Minore latenza e carico sui server upstream
- Comportamento più robusto con server che rispondono diversamente a HEAD vs GET
