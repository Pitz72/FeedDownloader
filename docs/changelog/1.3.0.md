# Changelog v1.3.0

**Data:** 12 maggio 2026

## Redesign UI integrale — "Electric Azure on Deep Dark"

La v1.3.0 introduce un **ridisegno completo dell'interfaccia** basato sul handoff bundle "FeedDownloader Pro" di Claude Design (claude.ai/design). La logica applicativa, le API IPC e i servizi sono invariati: cambia il design system, la struttura visuale dei componenti e l'identità grafica.

### Nuovo design system (v1.3.0)

**Palette superfici** — passaggio da grigi neutri a **scuri caldi quasi-neri**:

* `--bg #0a0a0c`, `--bg-deep #060608`
* `--surf-1 #111116` → `--surf-2 #16161d` → `--surf-3 #1d1d25` → `--surf-4 #25252f`
* Bordi: `--border #25262e`, `--border-soft rgba(255,255,255,0.06)`, `--border-hard rgba(255,255,255,0.12)`

**Primary — electric azure**:

* `--azure #4b8eff` (main button)
* `--azure-hi #75abff` (hover), `--azure-lo #2b6fe6` (active)
* `--azure-soft #adc6ff` (testo accent su dark)
* `--azure-glow` / `--azure-glow-sm` per shadow e ring

**Tipografia**:

* `--font-display` = Epilogue (titoli)
* `--font-body` = Inter (testo corrente)
* `--font-mono` = JetBrains Mono (kicker, meta, monospace)

**Radii**: sm 4 / md 8 / lg 12 / xl 16 / pill 999.

I token Tailwind v4 (`@theme`) e gli alias `--color-*` legacy sono mappati al nuovo sistema, mantenendo la compatibilità progressiva.

### Note tecniche

* **Font Inter + JetBrains Mono** caricati via Google Fonts CDN (Epilogue + Space Grotesk + Material Symbols restano via `@fontsource/*` bundled). In un futuro punto release potranno essere bundled per uso offline.
* **Auto-update**: gli utenti su v1.2.4 ricevono l'aggiornamento via la pipeline `Ecosystem-Runtime/FeedDownloader-Releases` (vedi migrazione 12 maggio 2026).
* **Compatibilità**: nessuna breaking change a livello di storage (SQLite archive, localStorage feedlist, settings JSON).
* **Build**: lint clean, `tsc --noEmit` clean, `vite build` 941 modules in ~2 s.
