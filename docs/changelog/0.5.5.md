# v0.5.5 — Sidecar Metadata .json

> Rilasciato il 26 marzo 2026
> Versione precedente: [v0.5.4](0.5.4.md)

Aggiunta la funzionalità **Sidecar .json**: per ogni episodio scaricato, l'applicazione può salvare un file `.json` nella stessa cartella dell'audio con i metadati completi dell'episodio. Funzionalità opt-in (disabilitata di default), attivabile dalle Impostazioni con un toggle.

---

## ✅ Nuova Feature

### Sidecar Metadata Files

**File modificati/creati:** `electron/ipc.ts`, `electron/services/DatabaseService.ts`, `electron/services/LibraryService.ts`, `shared/types.ts`, `electron/preload.ts`, `src/vite-env.d.ts`, `src/components/SettingsModal.tsx`, `src/locales/*.json` (8 lingue)

#### Comportamento

Quando il sidecar è abilitato, dopo ogni download completato con successo viene scritto un file `.json` con lo stesso nome base del file audio:

```
downloads/
  My Podcast/
    2024-03-15 - Episodio 42.mp3
    2024-03-15 - Episodio 42.json   ← sidecar (nuovo)
```

#### Contenuto del sidecar

```json
{
  "title": "Episodio 42",
  "podcast": "My Podcast",
  "guid": "episode-42-guid",
  "pubDate": "2024-03-15T10:00:00.000Z",
  "downloadedAt": "2026-03-26T14:30:00.000Z",
  "sourceUrl": "https://cdn.podcast.com/ep42.mp3",
  "filename": "2024-03-15 - Episodio 42.mp3"
}
```

Il sidecar è compatibile con il **template naming** (v0.5.4): il nome del file `.json` segue lo stesso nome risolto dal template, sostituendo solo l'estensione.

#### Implementazione

```typescript
// electron/ipc.ts — dopo addArchiveEntry, prima di pushEvent
if (libraryService.getSidecarEnabled()) {
    const sidecarPath = path.join(
        path.dirname(targetFile),
        path.parse(targetFile).name + '.json'
    );
    const sidecar = { title, podcast: podcastTitle, guid, pubDate, downloadedAt, sourceUrl, filename };
    await fs.writeJSON(sidecarPath, sidecar, { spaces: 2 }).catch(() => { });
}
```

**Nota:** il sidecar usa `.catch(() => {})` — un errore di scrittura non interrompe il download né genera un errore UI. Il file audio è già salvato correttamente.

#### UI in Impostazioni

Toggle switch nella sezione Storage, dopo il campo Template Nome File. Stile consistente con il design system (pill toggle blu/grigio).

#### Persistenza

La preferenza è salvata in SQLite nella tabella `settings` con chiave `sidecarEnabled`. Default: `false`.

## 🔌 API IPC aggiunta

| Channel | Tipo | Descrizione |
|---|---|---|
| `get-sidecar-enabled` | `invoke` | Legge la preferenza (boolean) |
| `set-sidecar-enabled` | `invoke` | Imposta la preferenza |

## 🌍 Localizzazione

Aggiunte 2 chiavi i18n in `settings` per tutte e 8 le lingue:

| Chiave | IT | EN |
|---|---|---|
| `settings.sidecar_enabled` | File Sidecar .json | Sidecar .json Files |
| `settings.sidecar_hint` | Salva un file .json accanto ad ogni audio... | Save a .json file next to each audio... |
