# Changelog v1.3.9

**Data:** 29 maggio 2026

## Criticità lievi (L1–L8)

Chiusura delle criticità **lievi** dell'audit del 29 maggio 2026 — ultimo blocco del ciclo.

### L1 — Logica durata duplicata e incoerente

`EpisodeList` ed `EpisodeDetailPanel` avevano ciascuno la propria
`parseDurationMinutes` / `formatDuration`, divergenti (una scartava i secondi).

* Estratta un'unica utility `src/utils/duration.ts` (`parseDurationSeconds`,
  `parseDurationMinutes`, `formatDuration`), usata da entrambi i componenti.

### L2 — Id toast collidibile

L'id del toast era `Math.random().toString(36).substring(7)` — poteva collidere (o
risultare stringa vuota), rompendo le `key` React e il filtro di rimozione.

* Sostituito con un contatore monotono (`toast-${++seq}`).

### L3 — Pulsante "rimuovi feed" irraggiungibile da tastiera

Il pulsante era `opacity: 0` e diventava visibile solo con `onMouseEnter`.

* Aggiunti `onFocus`/`onBlur`: ora compare anche quando raggiunto con Tab.

### L4 — Nessun rilascio risorse allo spegnimento

Niente chiusura del DB né stop del timer di auto-refresh all'uscita.

* Nuova `cleanup()` (stop timer + `db.close()`) invocata da `app.on('will-quit')`;
  aggiunto `LibraryService.close()`.

### L5 — La CI non eseguiva lint/test/audit

* Nuovo job `verify`: **lint + type-check renderer + type-check main** (bloccanti) e
  **test + `npm audit`** (informativi, `continue-on-error`, finché la suite test non è
  riparata). I job di build dipendono ora da `verify`. I build eseguono anche il
  type-check del main (`tsc -p tsconfig.electron.json`).

### L6 — Auto-update senza code-signing Windows (limite noto)

L'eseguibile Windows non è firmato: SmartScreen mostra l'avviso "Ulteriori informazioni
→ Esegui comunque". La firma richiede un certificato di code-signing a pagamento e non è
risolvibile via codice — documentata come limitazione nota, coerente con la distribuzione
non firmata già descritta nel manuale.

### L7 — `IMPORT_OPML` senza limite di dimensione

* Cap di 5 MB verificato (`fs.stat`) prima di leggere il file in memoria.

### L8 — Copia link senza feedback

I link nel pannello dettaglio copiavano negli appunti da un `<a href="#">` senza alcun
riscontro.

* Aggiunto toast di esito (`toast.copied` / `toast.copy_failed`) su successo/errore;
  nuove chiavi i18n in tutte e 8 le lingue.

### Verifica

* `npm run lint` — clean. `tsc --noEmit` (renderer+preload) — clean.
  `tsc -p tsconfig.electron.json` (main) — clean. `vite build` — OK.

### File modificati

* `src/utils/duration.ts` — nuova utility condivisa (L1).
* `src/components/EpisodeList.tsx`, `EpisodeDetailPanel.tsx` — usano la utility (L1); toast copia (L8).
* `src/context/ToastContext.tsx` — id toast monotono (L2).
* `src/components/Sidebar.tsx` — focus/blur sul pulsante rimuovi (L3).
* `electron/main.ts` — hook `will-quit` → `cleanup()` (L4).
* `electron/ipc.ts` — `cleanup()` esportata (L4); cap dimensione OPML (L7).
* `electron/services/LibraryService.ts` — `close()` (L4).
* `.github/workflows/build.yml` — job `verify` + doppio type-check nei build (L5).
* `src/locales/*.json` — chiavi `toast.copied` / `toast.copy_failed` (8 lingue, L8).
* `package.json` 1.3.8 → 1.3.9, badge README.
