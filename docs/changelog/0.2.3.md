# v0.2.3 - Cross-Platform Ready

## 🌍 Supporto Multi-Piattaforma
Questa versione introduce le configurazioni necessarie per compilare ed eseguire l'applicazione nativamente su **macOS** e **Linux**, oltre a Windows.

- **macOS**: 
    - Aggiunto styling specifico per le finestre ("traffic lights" integrati).
    - Configurato target di build `dmg` e `zip`.
- **Linux**:
    - Configurato target di build `AppImage` e `deb`.
- **Path Normalization**:
    - Verifica completa del codice per garantire che tutti i percorsi dei file siano gestiti correttamente su qualsiasi sistema operativo (uso stretto di `path.join`).

## 🛠️ Modifiche Sotto il Cofano
- Aggiornato `package.json` con le definizioni per `electron-builder` specifiche per Mac e Linux.
- Refactoring minore in `main.ts` per gestire le specificità di ogni piattaforma all'avvio.
