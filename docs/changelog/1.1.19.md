# Changelog v1.1.19

## F6 — Velocità e ETA inline per download attivo

Mostra velocità di download corrente e tempo stimato al completamento direttamente nella riga episodio, senza aprire il pannello di progresso.

### Funzionalità
- **Velocità corrente** (KB/s o MB/s) visualizzata sotto la percentuale durante il download attivo
- **ETA** (tempo rimanente stimato) affiancato alla velocità, separato da ` · `
- Formato ETA: `Xs` / `Xm Ys` / `Xh Ym` in base alla durata stimata
- Speed e ETA si aggiornano ad ogni evento di progresso
- Non mostrati se la velocità non è ancora disponibile (primo tick) o è 0

### Dettagli implementativi
- `speed?: number; eta?: number` aggiunti a `DownloadProgress` in `shared/types.ts`
- `speedCache: Map<string, { loaded: number; time: number }>` module-level in `useStore.ts`
- Calcolo in `updateDownload`: `speed = Δbytes / Δseconds`, `eta = remaining / speed`
- Pulizia della cache su `completed` / `error`
- `formatSpeed(bytesPerSec)` e `formatEta(seconds)`: pure functions in `EpisodeList.tsx`
- UI aggiornata: il blocco `isDownloading` ora usa `flex-col items-end` per stacking verticale
