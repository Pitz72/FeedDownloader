# Changelog v1.1.17

## E7 — `lastUpdated` sidebar aggiornato al sync

La data mostrata nella sidebar per ogni feed riflette ora l'ultimo sync effettivo, non più solo la data di prima aggiunta.

### Problema
`PARSE_FEED` effettuava la fetch di rete ma non aggiornava mai il campo `lastUpdated` nel DB. Solo `ADD_FEED` (prima aggiunta) scriveva la data. Ogni successivo sync/click sul feed non aggiornava la sidebar.

### Fix
- Aggiunto `touchFeed(url, lastUpdated)` in `DatabaseService` — `UPDATE feeds SET lastUpdated = ? WHERE url = ?`
- Aggiunto passthrough `touchFeed()` in `LibraryService`
- In `ipc.ts` handler `PARSE_FEED`: dopo ogni fetch di rete (non su cache hit), chiama `libraryService.touchFeed(url, new Date().toISOString())` e pusha `FEEDS_UPDATED` per aggiornare la sidebar in tempo reale

### Comportamento
- **Cache hit** (≤ 5 minuti): `lastUpdated` non viene toccato — nessuna fetch reale, data invariata
- **Fetch di rete**: `lastUpdated` aggiornato all'istante della risposta; sidebar si aggiorna immediatamente
- Se il feed non è ancora nel DB (analisi prima di aggiungere): `UPDATE` non trova righe → no-op sicuro

### File modificati
- `electron/services/DatabaseService.ts` — `touchFeed()`
- `electron/services/LibraryService.ts` — `touchFeed()` passthrough
- `electron/ipc.ts` — `PARSE_FEED` aggiorna DB + push `FEEDS_UPDATED`
