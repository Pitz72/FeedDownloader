# v0.6.6 — Filtro Durata Episodi

**Data:** 26 marzo 2026

## Novità

### Filtro per Durata (min/max minuti)
- Nuovo stato `minDuration` / `maxDuration` in `EpisodeList.tsx` (0 = nessun limite)
- Utility locale `parseDurationMinutes(duration?)`: supporta i formati `HH:MM:SS`, `MM:SS` e numero puro di secondi
- Utility `formatDuration(duration?)`: converte in formato leggibile (`1h 30m` / `45 min`)
- Il filtro durata viene applicato dopo il filtro stato nella catena `filteredEpisodes`
- Se `itunes?.duration` è assente, l'episodio passa sempre il filtro (comportamento permissivo)
- Pulsante "Duration Filter" (icona `Clock`) nella toolbar, accanto al pulsante "Date Filter"
- Pannello collassabile con due input numerici `Min` / `Max` e pulsante "Clear" (visibile solo se almeno uno dei valori è > 0)
- Durata mostrata in ogni riga episodio accanto alla data, se `episode.itunes?.duration` è presente

### Mapping `itunes.duration` dal feed RSS
- `Episode.itunes?: { duration?: string }` aggiunto a `shared/types.ts`
- `itunes: item.itunes` aggiunto al mapping episodi in `FeedService.parseFeed`

### Localizzazione
- Aggiunte chiavi `duration_filter`, `min_duration`, `max_duration` in tutti e 8 i file `src/locales/*.json`

## Note Tecniche

- `parseDurationMinutes`: regex `/^\d+$/` per secondi puri, poi split su `:` per MM:SS e HH:MM:SS
- Nessuna nuova dipendenza
- Il campo `itunes` di `rss-parser` è già esposto nativamente; non è necessario configurare `customFields`
