# v0.7.2 — Allineamento UI: SettingsModal, HelpModal, Sidebar

**Data:** 27 marzo 2026

## Modifiche

### SettingsModal — design system completo

Tutte le classi Tailwind hardcoded (`bg-gray-950`, `text-white`, `bg-blue-600`, ecc.) sostituite con CSS design token.

**Struttura:**
- Pannello: `var(--color-surface-container-lowest)` + `inset-shadow`
- Header: `var(--color-surface-container-low)` + separatore con `rgba(65,71,85,0.2)`
- Nav sinistra: bordo attivo `var(--color-primary)`, sfondo attivo `rgba(173,198,255,0.1)`

**Sezioni contenuto:**
- Heading sezioni: colori semantici (`primary`, `warning`, `secondary`, `error`) via CSS vars
- Input/select: `surface-container` + bordo `rgba(65,71,85,0.3)`
- Toggle (sidecar, id3): attivo `primary-container`, inattivo `surface-container-highest`
- Concorrenza: bottoni attivi `primary-container` / inattivi `surface-container`
- Stats archivio: carte `.bento-card`
- Health check: heading `warning`, contatore presenti `primary`, contatore mancanti `error`
- Migrazione archivio: colori `secondary` per heading, progresso e pulsante
- Dati / OPML: sfondo `surface-container-low` con hover
- Danger zone: colori `error` per heading, pulsante e schermata di conferma

**Aggiunto helper interno** `sectionHeading(color)` per uniformare le intestazioni di sezione.

### HelpModal — design system completo

- Pannello: `surface-container-low` + `inset-shadow`
- Header/Footer: `surface-container` + separatori
- Titolo: font `var(--font-headline)`, colore `var(--color-on-surface)`
- Markdown components: tutti i tag (`h1`–`h3`, `p`, `ul`, `strong`, `a`, `code`) usano CSS vars
- `h2` nel contenuto: colore `var(--color-primary)` (era `text-blue-400`)
- `code` inline: sfondo `surface-container-highest`, colore `secondary`
- Aggiunto handler Esc per chiusura

### Sidebar — fix "Data Sconosciuta"

Quando `lastUpdated` è null (feed mai sincronizzato), ora mostra `—` invece di "Data Sconosciuta" / "Unknown Date". La data viene valorizzata alla prima sincronizzazione.
