# Changelog v1.1.16

## E6 — Path download visibile nella UI principale

Il percorso di download attivo è ora sempre visibile nella sidebar, senza dover aprire le Impostazioni.

### Funzionalità
- **Footer sidebar**: riga cliccabile con icona `folder` e le ultime 2 componenti del path (es. `Documenti/Podcast`)
- Click sul path → apre la cartella nel file manager di sistema
- Il path si aggiorna in tempo reale quando cambiato da:
  - Pulsante "Cambia Cartella" in EpisodeList
  - Impostazioni → Download → Percorso Download
  - Migrazione archivio

### Implementazione
- Nuovo IPC `OPEN_FOLDER` → `shell.openPath(dirPath)` in `electron/ipc.ts`
- Esposto come `window.api.openFolder(dirPath)` in `preload.ts` e `vite-env.d.ts`
- `downloadPath: string` aggiunto allo Zustand store (`useStore.ts`)
- Inizializzato in `App.tsx` al mount via `window.api.getDownloadPath()`
- Sincronizzato dallo store in `EpisodeList.tsx` e `SettingsModal.tsx` ad ogni cambio path

### File modificati
- `shared/types.ts` — `OPEN_FOLDER` channel
- `electron/ipc.ts` — handler `OPEN_FOLDER`
- `electron/preload.ts` — `openFolder` API
- `src/vite-env.d.ts` — tipo `openFolder`
- `src/store/useStore.ts` — `downloadPath` + `setDownloadPath`
- `src/App.tsx` — init downloadPath al mount
- `src/components/EpisodeList.tsx` — aggiorna store su cambio cartella
- `src/components/SettingsModal.tsx` — aggiorna store su cambio/migrazione path
- `src/components/Sidebar.tsx` — path display nel footer
