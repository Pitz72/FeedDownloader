# Changelog v0.0.3 - UX Improvements & Stabilization

## 🚀 New Features

### Custom Download Folder
-   **Folder Selection**: Added a "Folder" button (📂) to the main search bar.
-   **Persistence**: The application now remembers your last selected download folder.
-   **Subfolder Organization**: Downloads are automatically organized into subfolders by podcast name (e.g., `SelectedFolder/PodcastName/EpisodeTitle.mp3`).

## 🛠 Fixes & Improvements

### UI/UX Polish
-   **White Flash Fix**: Eliminated the white flash on startup by setting the main window background color to match the dark theme (`#0b1120`).
-   **Glassmorphism**: Refined CSS to ensure consistent transparency and blur effects.

### Stability
-   **Feed Parsing Crash**: Fixed a critical bug where `FeedService` was not correctly mapping the RSS item structure, causing the application to crash upon analysis.
-   **Syntax Errors**: Resolved TypeScript syntax errors in `UrlInput.tsx` that were preventing the build.

## Technical Details
-   Updated `FeedService.ts` to explicitly map `items` to a consistent `episodes` interface.
-   Updated `main.ts` to handle window background color.
-   Exposed `chooseFolder`, `getDownloadPath`, and `setDownloadPath` via IPC for secure renderer access.
