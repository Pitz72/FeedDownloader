# Changelog v0.3.2

**Release Date:** 2026-02-16

## 🛠 Fixes & Improvements

### UX & Interface
- **Standardized Notifications**: Replaced system alerts with elegant `Toast` notifications for OPML Import/Export and CSV Export.
- **Deep Localization**: Added missing translations for Settings and Help modals. Now 100% localized.
- **Tooltip Logic**: Fixed tooltip messages for the "Reset Database" button when a download is in progress.

### Core & Stability
- **Safe Downloads**: Implemented `.part` temporary files for downloads. Files are renamed to `.mp3` only after successful completion, preventing corrupted files in case of crashes or interruptions.
- **Error Handling**: Improved error feedback during OPML import.
