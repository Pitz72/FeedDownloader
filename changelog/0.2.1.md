# v0.2.1 - In-App Documentation System

## 📘 Guida Integrata
Ora la documentazione non è solo inclusa, ma è **viva** dentro l'applicazione.
- **Help In-App**: Aggiunto un sistema di visualizzazione della guida che legge direttamente i file README localizzati.
- **Contestuale**: L'applicazione apre automaticamente la guida nella lingua selezionata dall'utente.
- **Accessibilità**: La guida è accessibile sia dalla schermata iniziale (icona Libro) che dal menu Impostazioni.
- **UI/UX**: Renderizzata in Markdown con stile "Dark Mode" per una lettura confortevole senza uscire dall'app.

## 🛠️ Modifiche Tecniche
- Implementato handler IPC `get-help-content` per la lettura dinamica delle risorse.
- Configurato `electron-builder` per distribuire i file `.md` nella cartella risorse dell'applicazione installata.
