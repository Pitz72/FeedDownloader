# v0.3.1 - Fix & Polish

## 🛠️ Correzioni Critiche
- **Anchor.fm Fix**: Risolto un problema per cui alcuni feed (es. Anchor.fm) non mostravano l'immagine di copertina e fallivano il download. Ora il sistema legge correttamente anche i tag `itunes:image`.
- **Coda Download Intelligente**: Risolto un bug nella gestione della coda. Ora, se aggiungi altri episodi mentre un download massivo è in corso, il contatore totale si aggiorna correttamente invece di resettarsi.

## 🎨 UI & UX
- **Scrollbar Personalizzate**: le barre di scorrimento laterali sono state ridisegnate per integrarsi perfettamente con il tema scuro "Glassmorphism" dell'applicazione, abbandonando lo stile di default del sistema operativo.

## 🌍 Internazionalizzazione
- **Traduzione Completa**: Eliminate le ultime stringhe in italiano che apparivano ancora nelle finestre di conferma e nei messaggi di errore. Ora l'applicazione rispetta al 100% la lingua selezionata (Inglese, Spagnolo, ecc.).
