# Runtime FeedDownloader Pro

Версия 1.3.13

Самый мощный способ архивирования ваших подкастов.

## Что это

Runtime FeedDownloader Pro — это профессиональный инструмент, разработанный для архивистов, издателей и энтузиастов, которым необходимо скачивать целые каталоги подкастов для офлайн-хранения.
В отличие от обычных плееров, эта программа оптимизирована для массовой загрузки (Batch), устойчивости к сбоям сети и структурированной организации файлов на диске.

## Основные Возможности

### Управление лентами

* **Постоянная Библиотека Лент:** Управляйте несколькими подкастами одновременно с помощью боковой панели с изменяемой шириной, поиском и сортировкой A–Z; ленты сохраняются между сессиями.
* **Значок «К Загрузке»:** Числовой индикатор у каждой ленты, показывающий, сколько эпизодов ещё нет в вашем архиве.
* **Обнаружение Новых Эпизодов:** Основано на GUID эпизодов, а не на простом подсчёте — уведомления остаются надёжными даже для подкастов со «скользящим окном», удаляющих старые выпуски.
* **Постраничные Ленты (RFC 5005):** Автоматически переходит по ссылкам на следующие страницы ленты, восстанавливая полный каталог, даже если провайдер (Apple Podcasts, Libsyn, Blubrry…) публикует на первой странице только последние эпизоды.
* **Sync All с прогрессом по каждой ленте:** Обновляет все ленты параллельно; каждая миниатюра показывает свой статус в реальном времени.
* **Автоматическое Обновление Лент:** Фоновый таймер (6/12/24 ч) с системным уведомлением о новых эпизодах.

### Загрузки и очередь

* **Пакетная Загрузка:** Скачивайте сотни эпизодов одним кликом, с интеллектуальным управлением очередью и настраиваемым числом параллельных загрузок (1, 3 или 5).
* **Ограничение Скорости:** Настраиваемая максимальная скорость загрузки в Настройках (0 = без ограничений).
* **Панель Загрузок:** Боковая панель с очередью, скоростью (КБ/с), оставшимся временем и журналом ошибок для каждого пакета. Плавающая кнопка позволяет открыть её снова, не теряя загрузки.
* **Скорость и Оставшееся Время:** Отображаются прямо в строке каждого активного эпизода.
* **Отмена Отдельной Загрузки:** Отмените одну загрузку из очереди, не останавливая остальные.
* **Повторная Загрузка Эпизода:** Возможность заново скачать эпизод, уже находящийся в архиве.
* **Множественный Выбор:** Ctrl+клик / Shift+клик для выбора диапазонов эпизодов и их совместной загрузки.

### Интерфейс и навигация

* **Современный Дизайн «Electric Azure on Deep Dark»:** Полностью переработанный тёмный интерфейс — быстрый и читаемый.
* **Палитра Команд (Ctrl+K):** Быстрый доступ ко всем основным действиям и сохранённым лентам без мыши.
* **Панель Сведений об Эпизоде:** Клик по эпизоду открывает панель с полными метаданными, данными архива и заметками к выпуску.
* **Сортировка Эпизодов:** Сортируйте список по дате, названию или длительности, помимо исходного порядка ленты.
* **Вид Архива:** Отдельная вкладка для просмотра, поиска и сортировки всего архива скачанных эпизодов.
* **Экспорт Плейлистов M3U:** Создаёт локальные плейлисты, совместимые с любым аудиоплеером.
* **Обучающие Подсказки:** Подсказки при первом запуске, чтобы сразу начать работу.

### Устойчивость и целостность

* **Движок «Database-First»:** Система помнит, что вы скачали, независимо от файлов на диске (SQLite).
* **Устойчивые Загрузки:** Тайм-аут соединения (30 с) и обнаружение зависаний (60 с), автоматические повторные попытки с экспоненциальной задержкой, файлы `.part` для защиты от повреждений.
* **Целостность Данных:** Автоматический расчёт SHA-256 и извлечение аудиометаданных (битрейт, частота дискретизации) после загрузки.
* **Health Check:** Автоматическое восстановление отсутствующих на диске эпизодов с ресинхронизацией базы данных.

### Организация и переносимость

* **Реальное Расширение:** Определяет и сохраняет фактический формат файла (`.m4a`, `.ogg`, `.opus`, `.flac`…), не навязывая всегда `.mp3`.
* **Теги ID3 с Обложкой:** Автоматически записывает теги ID3 в файлы `.mp3`, отдавая приоритет обложке конкретного эпизода, если она доступна.
* **Шаблоны Переименования:** Настраиваемые токены (`{{title}}`, `{{date}}`, `{{podcast}}`) для упорядоченных имён файлов.
* **Переносимость Данных:** Импортируйте и экспортируйте ленты по стандарту OPML. Создавайте подробные CSV-отчёты о вашем архиве.
* **Миграция Архива:** Перенесите всю библиотеку на новый путь/диск с автоматическим обновлением базы данных.
* **Поддержка NAS/SMB:** Нативная проверка и тайм-аут (8 с) для сетевых путей — без зависания интерфейса.

### Система и безопасность

* **Автообновление с Уведомлением:** Автоматические обновления через GitHub Releases с системным уведомлением, когда обновление доступно и когда оно готово к установке.
* **Безопасность URL:** Анти-SSRF-проверка на уровне соединения — блокирует опасные протоколы, частные IP-адреса, зарезервированные адреса и вредоносные перенаправления, для каждой страницы ленты.
* **Smart Truncate:** Автоматически переименовывает файлы, чтобы избежать ошибок длины пути в Windows.
* **Производительность:** Виртуализированный список — обрабатывает ленты с тысячами эпизодов без замедлений.
* **Встроенная Справка:** Руководство пользователя доступно прямо внутри приложения.

## Многоязычная Сертификация

Программа полностью поддерживает **8 языков**: Italiano (IT), English (EN), Français (FR), Deutsch (DE), Español (ES), Português (PT), Русский (RU), 中文 (ZH). Интерфейс, системные уведомления и документация доступны на всех языках.

## Краткая Инструкция

1. **Анализ:** Вставьте URL RSS-ленты в главную строку и нажмите «Анализировать». Лента будет добавлена в боковую панель для дальнейшего доступа.
2. **Выбор Папки:** В Настройках → Архив укажите папку для сохранения файлов. Путь всегда виден в нижней части боковой панели.
3. **Загрузка:** Используйте кнопку «Скачать Всё» для всего каталога или выберите эпизоды с помощью Ctrl+клик и нажмите «Скачать Выбранные».
4. **Мониторинг:** Панель Загрузок открывается автоматически, показывая очередь, скорость и оставшееся время для каждого файла.
5. **Управление:** Используйте Ctrl+K для Палитры Команд или Настройки (⚙) для параллельности, ограничения скорости, шаблонов, OPML и статистики архива.

## Системные Требования

Программа кроссплатформенная и работает нативно на:

* **Windows**: 10/11 (64-бит) — установщик NSIS (`.exe`)
* **Linux**: Современные дистрибутивы (Ubuntu 20.04+, Debian 11+, Fedora 34+) — `.AppImage` или `.deb`
* **macOS**: 11.0 (Big Sur) и выше — поддерживается кодом, но пакеты для macOS в настоящее время не распространяются
* Активное подключение к Интернету

## Загрузка

Официальные пакеты доступны на [GitHub Releases](https://github.com/Ecosystem-Runtime/FeedDownloader-Releases/releases) и собираются через GitHub Actions.

| Платформа | Формат | Примечания |
|---|---|---|
| Windows 10/11 | `.exe` (установщик NSIS) | Программа не подписана — см. примечание о SmartScreen |
| Linux | `.AppImage` / `.deb` | Подпись не требуется |

**Windows — предупреждение SmartScreen:** При первом запуске Windows Defender может показать экран «Система Windows защитила ваш компьютер — Неизвестный издатель». Программа безопасна. Нажмите **Подробнее** → **Выполнить в любом случае**.

**macOS:** Пакеты `.dmg` в настоящее время не публикуются; приложение можно собрать из исходного кода.
