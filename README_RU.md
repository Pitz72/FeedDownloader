# Runtime FeedDownloader Pro
**Самый мощный способ архивирования ваших подкастов.**

## Что это
Runtime FeedDownloader Pro — это профессиональный инструмент, разработанный для архивистов, издателей и энтузиастов, которым необходимо скачивать целые каталоги подкастов для офлайн-хранения.
В отличие от стандартных плееров, это программное обеспечение оптимизировано для массовой загрузки (Batch), устойчивости сети и организации файловой системы.

## Основные характеристики
- **Движок "Database-First":** Система запоминает, что вы скачали, независимо от файлов на диске.
- **Пакетная загрузка:** Скачивайте сотни эпизодов одним кликом с интеллектуальным управлением очередью.
- **Smart Truncate:** Автоматически переименовывает файлы, чтобы избежать ошибок длины пути в Windows.
- **Устойчивость:** Автоматически повторяет загрузки при разрыве соединения.
- **Производительность:** Обрабатывает фиды с тысячами эпизодов без замедлений.

## Краткие инструкции
1.  **Анализ:** Вставьте URL RSS-фида в главную строку и нажмите "Анализировать".
2.  **Выбор папки:** Нажмите значок папки, чтобы выбрать место сохранения архива.
3.  **Скачать:** Используйте кнопку "Скачать все" для всего архива или скачивайте отдельные эпизоды вручную.
4.  **Управление:** Используйте Настройки (значок шестеренки) для управления языком или сброса базы данных.

## Требования
- Windows 10/11 (64-бит)
- Активное подключение к Интернету
