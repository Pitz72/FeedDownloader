# Runtime FeedDownloader Pro
**Самый мощный способ архивирования ваших подкастов.**

## Что это
Runtime FeedDownloader Pro — это профессиональный инструмент, разработанный для архивистов, издателей и энтузиастов, которым необходимо скачивать целые каталоги подкастов для офлайн-хранения.
В отличие от стандартных плееров, это программное обеспечение оптимизировано для массовой загрузки (Batch), устойчивости сети и организации файловой системы.

## Основные характеристики
- **Движок "Database-First":** Система запоминает, что вы скачали, независимо от файлов на диске.
- **Пакетная загрузка:** Скачивайте сотни эпизодов одним кликом с интеллектуальным управлением очередью.
- **Переносимость данных:** Импортируйте и экспортируйте фиды через стандарт OPML. Создавайте подробные CSV-отчеты вашего архива.
- **Расширенная безопасность:** Система защиты от повреждений при переполнении диска, умный офлайн-режим и валидация входящих фидов.
- **Встроенная справка:** Полное руководство пользователя доступно прямо в приложении.
- **Smart Truncate:** Автоматически переименовывает файлы, чтобы избежать ошибок длины пути в Windows.
- **Устойчивость:** Автоматически повторяет загрузки при разрыве соединения.
- **Производительность:** Обрабатывает фиды с тысячами эпизодов без замедлений.

## Краткие инструкции
1.  **Анализ:** Вставьте URL RSS-фида в главную строку и нажмите "Анализировать".
2.  **Выбор папки:** Нажмите значок папки, чтобы выбрать место сохранения архива.
3.  **Скачать:** Используйте кнопку "Скачать все" для всего архива или скачивайте отдельные эпизоды вручную.
4.  **Управление:** Используйте Настройки (значок шестеренки) для управления языком или сброса базы данных.

## Системные требования
Программное обеспечение кроссплатформенное и работает нативно на:
- **Windows**: 10/11 (64-бит)
- **macOS**: 11.0 (Big Sur) или выше (Intel и Apple Silicon)
- **Linux**: Современные дистрибутивы (Ubuntu, Debian, Fedora) через AppImage или .deb
- Активное подключение к Интернету

## Загрузка

Официальные пакеты для всех платформ доступны на [GitHub Releases](https://github.com/Pitz72/FeedDownloader/releases) и создаются автоматически через GitHub Actions.

| Платформа | Формат | Примечания |
|---|---|---|
| Windows 10/11 | `.exe` (установщик NSIS) | Без подписи — см. примечание SmartScreen |
| macOS 11+ | `.dmg` / `.zip` | Без подписи — см. примечание Gatekeeper |
| Linux | `.AppImage` / `.deb` | Подпись не требуется |

**Windows — предупреждение SmartScreen:** При первом запуске Windows Defender может показать экран «Windows защитила ваш компьютер — Неизвестный издатель». Программа безопасна. Нажмите **Подробнее** → **Выполнить в любом случае**.

**macOS — предупреждение Gatekeeper:** Пакет не подписан сертификатом Apple Developer. При первом запуске macOS может заблокировать приложение. Для открытия: нажмите правой кнопкой мыши на приложение → **Открыть**, или перейдите в **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.

*Разработано с технологией Electron & React для обеспечения производительности и стабильности.*
