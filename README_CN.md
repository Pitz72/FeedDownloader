# Runtime FeedDownloader Pro

版本 1.3.13

存档播客的最强大方式。

## 是什么

Runtime FeedDownloader Pro 是一款专为档案管理员、出版商和爱好者设计的专业工具，用于下载整个播客目录以进行离线保存。
与普通播放器不同，本软件针对批量下载（Batch）、网络容错以及文件系统的结构化组织进行了优化。

## 主要功能

### 订阅源管理

* **永久订阅源库：** 通过可调节宽度的侧边栏同时管理多个播客，支持搜索和 A–Z 排序；订阅源在会话之间持久保存。
* **"待下载"徽章：** 每个订阅源上的数字指示器，显示尚未加入存档的剧集数量。
* **新剧集检测：** 基于剧集 GUID 而非简单计数——即使播客采用"滚动窗口"方式（发布新剧集的同时移除旧剧集），通知依然可靠。
* **分页订阅源（RFC 5005）：** 自动跟随订阅源后续页面的链接，即使提供商（Apple Podcasts、Libsyn、Blubrry 等）在首页只发布最新剧集，也能重建完整目录。
* **Sync All 逐源进度：** 并行刷新所有订阅源；每个缩略图实时显示各自的状态。
* **订阅源自动刷新：** 后台定时器（6/12/24 小时），发现新剧集时发送系统通知。

### 下载与队列

* **批量下载：** 一键下载数百个剧集，具备智能队列管理和可配置的并发数（1、3 或 5 个并行下载）。
* **速度限制：** 可在设置中配置最大下载带宽（0 = 不限速）。
* **下载面板：** 侧边抽屉式面板，显示每个批次的队列、速度（KB/s）、预计剩余时间和错误日志。悬浮按钮可随时重新打开面板而不中断下载。
* **速度与预计时间：** 直接在剧集行内显示每个进行中下载的速度和剩余时间。
* **单独取消：** 从队列中取消单个下载，而不影响其他下载。
* **重新下载剧集：** 可重新下载已存在于存档中的剧集。
* **多选：** Ctrl+点击 / Shift+点击选择剧集区间并一起下载。

### 界面与导航

* **现代设计"Electric Azure on Deep Dark"：** 全新重制的深色界面，快速且易读。
* **命令面板（Ctrl+K）：** 无需鼠标即可快速访问所有主要操作和已保存的订阅源。
* **剧集详情面板：** 点击剧集即可打开面板，查看完整元数据、存档数据和节目备注。
* **剧集排序：** 除订阅源原始顺序外，还可按日期、标题或时长对列表排序。
* **存档视图：** 专用标签页，用于浏览、搜索和排序所有已下载剧集的完整存档。
* **导出 M3U 播放列表：** 生成与任何音频播放器兼容的本地播放列表。
* **新手引导：** 首次启动时提供操作提示，帮助您立即上手。

### 容错与完整性

* **"Database-First" 引擎：** 系统会记住您下载过的内容，与磁盘上的文件无关（SQLite）。
* **高容错下载：** 连接超时（30 秒）与停滞检测（60 秒），指数退避自动重试，防损坏 `.part` 文件。
* **数据完整性：** 下载完成后自动计算 SHA-256 并提取音频元数据（比特率、采样率）。
* **健康检查：** 自动恢复磁盘上缺失的剧集，并重新同步数据库。

### 组织与可移植性

* **真实扩展名：** 检测并保存文件的真实格式（`.m4a`、`.ogg`、`.opus`、`.flac` 等），而不是一律强制使用 `.mp3`。
* **带封面的 ID3 标签：** 自动向 `.mp3` 文件写入 ID3 标签，如有剧集专属封面则优先使用。
* **重命名模板：** 可自定义的令牌（`{{title}}`、`{{date}}`、`{{podcast}}`），生成井然有序的文件名。
* **数据可移植性：** 通过 OPML 标准导入和导出订阅源。生成存档的详细 CSV 报告。
* **存档迁移：** 将整个库迁移到新路径/磁盘，数据库自动更新。
* **NAS/SMB 支持：** 对网络路径进行原生验证并设置超时（8 秒），界面不会卡死。

### 系统与安全

* **自动更新与通知：** 通过 GitHub Releases 自动更新，当有可用更新以及更新准备好安装时发送系统通知。
* **URL 安全：** 连接层面的反 SSRF 验证——拦截危险协议、私有 IP、保留地址和恶意重定向，对订阅源的每一页均生效。
* **智能截断：** 自动重命名文件，避免 Windows 上的路径长度错误。
* **性能：** 虚拟化列表——即使订阅源包含数千个剧集也不会卡顿。
* **内置帮助：** 可直接在应用内查阅用户指南。

## 多语言认证

本软件完整支持 **8 种语言**：Italiano (IT)、English (EN)、Français (FR)、Deutsch (DE)、Español (ES)、Português (PT)、Русский (RU)、中文 (ZH)。界面、系统通知和文档均提供所有语言版本。

## 快速指南

1. **分析：** 将 RSS 订阅源 URL 粘贴到主栏中，然后按"分析"。订阅源会添加到侧边栏，方便日后访问。
2. **选择文件夹：** 在 设置 → 存档 中设置保存文件的文件夹。路径始终显示在侧边栏底部。
3. **下载：** 使用"下载全部"按钮下载整个目录，或用 Ctrl+点击选择剧集后使用"下载所选"。
4. **监控：** 下载面板会自动打开，显示每个文件的队列、速度和预计剩余时间。
5. **管理：** 使用 Ctrl+K 打开命令面板，或通过设置（⚙）管理并发数、速度限制、模板、OPML 和存档统计。

## 系统要求

本软件为跨平台应用，可原生运行于：

* **Windows**：10/11（64 位）— NSIS 安装程序（`.exe`）
* **Linux**：现代发行版（Ubuntu 20.04+、Debian 11+、Fedora 34+）— `.AppImage` 或 `.deb`
* **macOS**：11.0（Big Sur）及以上 — 代码层面支持，但目前不分发 macOS 安装包
* 有效的互联网连接
