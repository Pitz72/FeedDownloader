# Runtime FeedDownloader Pro
**存档播客的最强大方式。**

## 是什么
Runtime FeedDownloader Pro 是一款专为档案管理员、出版商和爱好者设计的专业工具，用于下载整个播客目录以进行离线保存。
与标准播放器不同，此软件针对批量下载 (Batch)、网络弹性和文件系统组织进行了优化。

## 主要功能
- **"数据库优先"引擎：** 系统会记住您下载的内容，而不仅仅是磁盘上的文件。
- **批量下载：** 一键下载数百集，具有智能队列管理功能。
- **智能截断：** 自动重命名文件以避免 Windows 上的路径长度错误。
- **弹性：** 如果连接中断，自动重试下载。
- **性能：** 处理包含数千集的源而不会变慢。

## 快速说明
1.  **分析：** 将 RSS 源 URL 粘贴到主栏中，然后按“分析”。
2.  **选择文件夹：** 单击文件夹图标以决定保存存档的位置。
3.  **下载：** 使用“全部下载”按钮下载整个存档，或手动下载单个剧集。
4.  **管理：** 使用设置（齿轮图标）来管理语言或重置数据库。

## 要求
- Windows 10/11 (64位)
- 活跃的互联网连接

*使用 Electron & React 技术开发，以确保性能和稳定性。*
